4.8　循环中的输入问题 · 本节地图
三问循环里读输入，先答三问：循环何时停　/　这次读到的是谁　/　多余字符怎么办。

① 何时停

终止由程序内部确定（计数器），还是由输入的内容决定（结束标志）？

② 读到谁

字符用 getchar()，数值用 scanf()；读进来的可能不是你以为的那个字符。

③ 多余字符

一行里剩下的输入、上一行留下的回车，都要有人处理。

【例4-12】计数循环：10 个字符
原题：由键盘输入10个字符，输出各字符的ASCII编码。
运行结果（输入 20 个字符，只输出前 10 个）
备注已知字符个数，采用计数循环。
👉 先想一想
已知要输入 10 个字符，这段循环该怎么写？
点击显示参考代码
#include <stdio.h>
int main() {
    char c;
    int n;
    for(n=0;n<10;++n) {   //循环进行10次
        c=getchar();       //每次输入1个字符赋给c
        printf("%4d",c);   //输出字符c的ASCII码值
    }
    return 0;
}
终止方式第1种方式，循环的终止由程序内部确定，与外界输入的字符无关，如使用计数器。
【例4-13】结束标志：一行字符
原题：由键盘输入一行字符，输出字符的个数。　→　换行符为结束标记
#include <stdio.h>
int main()
{
    int c,n=0;
    c=getchar();              //输入第一个字符赋给c
    while(c!='\n') {           //判断c是否为回车符，是回车符循环结束
        ++n;                  //字符计数
        c=getchar();           //输入下一个要处理的字符赋给c
    }
    printf("%d characters!\n",n);
    return 0;
}
读-判顺序由题知，一行字符，则换行符为结束标记。先读入第一个字符，循环才有可能开始；每轮末尾再读下一个。
例4-13 的两种简写：读—判顺序没变

简写一　不保留读入的字符

while(getchar()!='\n')  ++n;

读入 + 判断一起写进循环条件，循环体只剩计数。

简写二　用 c 保留读入的字符

while((c=getchar())!='\n')  ++n;

赋值表达式的值就是读到的字符，后面还要用 c 时选这个。

逐轮推演① 读入一个字符　→　② 判断是不是 '\n'　→　③ 不是则 ++n，回到 ①；是则结束，回车不计数。
共同点两种写法都只把「有效字符」计入 n；结束标志本身没有进入循环体。
换成 do-while：回车也被数进去了
只留循环部分（原稿为完整程序）
    do{
        c=getchar();   //输入下一个要处理的字符赋给c
        ++n;           //字符计数
    } while(c!='\n'); //判断c是否为回车符，是回车符循环结束
    printf("%d characters!\n",  n );
运行结果：19 characters!
为什么是 19后测试循环先执行循环体、再判断条件：连结束标志 '\n' 也被 ++n 数了一次。原稿在旁边标注了改法：n-1，即输出时把多算的那一个减掉。
对照前测试 while：18 characters!（前测试的运行结果）；后测试 do-while：19 characters!。
两类终止方式，怎么选
终止方式循环条件由谁定典型写法本节例题
通过计数器控制循环程序内部（已知个数）for(n=0;n<10;++n)例4-12、例4-14
用结束标志控制的循环输入的内容本身while(c!='\n')例4-13、例4-15
第1种方式循环的终止由程序内部确定，与外界输入的字符无关，如使用计数器。
第2种方式程序根据输入的情况决定是结束循环还是继续循环。
边界结束标志到底算不算一次循环？看它在循环体里有没有被执行到——这正是 do-while 多出 1 的原因。
【例4-14】计数循环：12 个月降雨量
原题与备注已知每个月的降雨量，求出1年12个月的总降雨量。
备注（原稿）：已知是12个月，因此使用计数循环；循环内输入当月降水量。不是字符，只能使用scanf()。
#include <stdio.h>
int main()
{
    double x,sum;      //sum用来累积总降水量，x表示每月降水量
    int n;             //n作为循环变量，表示12个月
    for(sum=0,n=1;n<=12;n++) {
        printf("Enter next data : ");  //输入降水量提示
        scanf("%lf",&x);              //输入当前月的降水量给x
        sum+=x;                        //累加当前月的降水量到sum
    }
    printf("Annual Precipitation : %f\n",sum);
    return 0;
}
【例4-15】结束标志：货物总值
原题：计算一批货物的总值。每次输入的是货物单价和数量。（下面只留核心部分）
    float price=1,amount,sum=0;
        //price初值为1，防止进入循环时条件不成立
    while(price!=0) {
        printf("Enter next data (price amount): ");
        scanf("%f%f", &price,&amount);   //输入货物单价和数量
        sum+=price*amount;               //累加总值
    }
    printf("Total price: %.2f\n",sum);
单价为0时，结束这是结束标志控制的循环：读入的单价一旦为 0，下一轮条件 price!=0 不成立，循环终止。
初值不能省price=1 不是随便给的。若写成 0，循环一次都不会执行——条件一上来就是假。
小结：字符用 getchar，数值用 scanf

输入一系列字符

getchar() 一次读 1 个字符，连空格、回车都算字符；循环条件常写成 c!='\n'。

输入一批数据

scanf() 按格式读数值，循环内每轮读一组；个数已知用计数循环，否则约定一个结束标志。

把两件事分开循环结构决定读几次；输入函数决定每次读到什么。下一节的麻烦，几乎都出在后面这件事上。

7-8　最佳情侣身高差
专家通过多组情侣研究数据发现，最佳的情侣身高差遵循着一个公式：（女方的身高）×1.09 =（男方的身高）。如果符合，你俩的身高差不管是牵手、拥抱、接吻，都是最和谐的差度。
下面就请你写个程序，为任意一位用户计算他/她的情侣的最佳身高。
输入格式：输入第一行给出正整数N（≤10），为前来查询的用户数。随后N行，每行按照“性别 身高”的格式给出前来查询的用户的性别和身高，其中“性别”为“F”表示女性、“M”表示男性；“身高”为区间 [1.0, 3.0] 之间的实数。
输出格式：对每一个查询，在一行中为该用户计算出其情侣的最佳身高，保留小数点后2位。
输入样例： 2 / M 1.75 / F 1.8 输出样例： 1.61 / 1.96
N-S 图：计数循环 + 双分支选择
从图到代码循环体里先输入 gender 与 height，再按 gender=='M' 分成两支输出；i 每轮加 1，共 N 轮。下一页的学生代码就是照着这张图写的。
第一次提交：为什么只输出了一行
    int N,i=1;
    double a,b;
    char m;
    scanf("%d",&N);
    for(; i<=N; i++) {
        scanf("%c %lf",&m,&a);
        if(m=='M')  { b=a/1.09;  printf("%.2lf\n",b); }
        if(m=='F')  { b=a*1.09;  printf("%.2lf\n",b); }
    }
题目给的输入样例：2 / M 1.75 / F 1.8
2 M 1.75 1.61 （没有第二行）
现象N = 2，本该输出两行，实际只输出 1.61 一行。循环次数、公式都没写错——问题在 %c 究竟读到了什么。
先别急着改下一页用单步调试看变量 m 的值。
单步调试：m 里装的是换行符
第 1 轮（i = 1）：m = 10 '\n'
第 2 轮（i = 2）：m = 77 'M'
👉 点击显示诊断结论
结论第一次循环 i=1 时 m 读到的是 ASCII 10，即换行符，两个 if 都不成立，这一轮什么也没输出；到 i=2 才读到 'M'。所以 N=2 只出 1 行——第一次循环被上一行的回车吃掉了。
补：为什么偏偏是 %c 读到了回车
格式对待前导空白（空格 / 回车 / Tab）本例读到
%d、%f、%lf自动跳过，一直找到第一个非空白字符才开始读2
%c一个都不跳，缓冲区里下一个是什么就读什么'\n'（ASCII 10）
" %c"（格式串前加空格）格式串里的这个空格负责吃掉任意多个空白字符'M'
scanf("%d",&N);        // 读走 2，回车留在输入流里
scanf("%c %lf",&m,&a);  // %c 不跳空白，直接读走那个回车
一句话记住%c 是常用格式里唯一不跳过前导空白的；而 scanf 格式串里的一个空格并不表示「匹配一个空格」，而是「跳过任意多个空白字符」。

关键一步%d 只读走数字 2，它后面的回车没有被读走。第 1 轮 %c 不看类型、不跳空白，照单全收，读到的是 '\n'。
为什么第 2 轮又正常了第 1 轮的 %lf 撞上字母 M 匹配失败，但循环照常 i++；下一轮从 M 开始读，于是第 2 轮 %c 拿到了 'M'。
两种改法：把那个回车处理掉

改法一　循环内先吸收

for(; i<=N; i++) {
    getchar();
    scanf("%c %lf",&m,&a);
    ...
}

getchar() 吸收上一行残留的回车；在读 gender 之前先取走它。

改法二　格式串前加空格

//getchar();
scanf(" %c %f",&gender,&height);

① 注释掉 getchar()；② %c 前多一个空格，让 scanf 自己跳过前导空白。

两种改法，各自改了哪一步
改法一：getchar()改法二：" %c"
动手的位置循环体内加一条语句scanf 的格式串里加一个空格
谁吃掉回车程序显式读走一个字符scanf 按格式自动跳过空白
要注意每轮只吸收一个字符；前面若不止一个空白就不够无论前面有多少空白都能跳过

【例4-16】完成1个交互式的运算器
题目要求程序每读入1个形式正确的表达式后就计算并输出其结果。
Small Calculator
Enter any non-digit character to stop.
12.8*36.5⏎
    12.80*36.50=467.20
254#156⏎    跳过
254+143.8⏎
    254.00+143.80=397.80
1031.3-x⏎    跳过
1031.3-524⏎
    1031.30-524.00=507.30
a⏎    停止
原稿标注：两处「跳过」
两种结束方式输入 a 这样的非数值 → 停止；运算符或第二个运算数不合法 → 跳过本行，重新输入。
第①步　先搭框架
#include <stdio.h>
int main()
{
    float left,right,result;
    char op;
    printf("Small Calculator\n");
    printf("Enter any non-digit character to stop.\n");
    ……   // 运算器设计
    return 0;
}
自顶向下，逐步细化框架里先只写确定的部分：变量、两句提示。中间用 …… 占位，后面三步把它一段段补出来。
第②步　输入循环：用 scanf 的返回值作条件
while(scanf("%f", &left)==1) { //输入的第一个运算数是数字，循环进行.
op=getchar();      //输入的运算符给op
//输入的运算符超出了运算范围或第二个运算数不是数字，则重新输入
if((op!='+'&&op!='-'&&op!='*'&&op!='/')||scanf("%f",&right)!=1)
{
while(getchar()!='\n')   //跳过本行输入内容
continue;
continue;         //回到while循环，重新输入
}
}
两条要点备注（原稿）：当输入的第一个数据不为数值时，结束 → scanf("%f", &left)==1，使用scanf函数的返回值作为循环条件。
吸收多余字符：while(getchar()!='\n') continue; 把这一行剩下的字符全部读掉，下一轮才不会接着读到它们。
第③步　在循环里补上 switch
while(scanf("%f", &left)==1) {
    op=getchar();
    if( ... ) { 跳过本行; continue; }
    switch(op) {  //根据输入的op，输出相应的运算式和计算结果
        case '+':  ……
        case '-':  ……
        case '*':  ……
        case '/':  ……
    }
}
这一层只定结构四个 case 先留 ……，把「读表达式 → 判断合法性 → 按运算符分支」的骨架立起来；每个 case 里写什么，下一步再细化。
第④步　细化 switch（1）：加号与减号
/*细化：根据输入的op，输出相应的运算式和计算结果 */
switch(op){
    case '+':
        result=left+right;
        printf("%.2f+%.2f=%.2f\n", left, right, result);
        break;
    case '-':
        result=left-right;
        printf("%.2f-%.2f=%.2f\n", left, right, result);
        break;
每一支做三件事算结果 → 按 %.2f 输出运算式和结果 → break 跳出 switch。
第④步　细化 switch（2）：乘号与除号
    case '*':
        result=left*right;
        printf("%.2f*%.2f=%.2f\n", left, right, result);
        break;
    case '/':
        if(right!=0) {
            result=left/right;
            printf("%.2f/%.2f=%.2f\n", left, right, result);
        } else
            printf("Error!divider is 0!\n");
}
说明除法分支先判 right!=0，为 0 时输出 Error!divider is 0!。
本段按教材原稿照录（包括末尾右花括号的位置与 case '/' 分支的写法），未作语法调整。

题目设ch1为char类型变量，若由键盘上输入以下数据：right?<回车>，则以下3个程序段的输出结果分别是______，______，______。
（1） c=getchar();
      while(c!='?')
        { putchar(c);     c=getchar(); }
（2）while((c=getchar())!='?')
           putchar(++c);
（3）while(putchar(getchar())!='?');

循环需考虑和解决的问题
  • (１)循环中涉及哪些变量?
  • (２)循环开始前应赋给它们什么初值?
  • (３)循环中这些变量应如何随之变化?
  • (４)在什么情况下应该继续(或终止)循环?
  • (５)循环终止后如何得到所需结果?
