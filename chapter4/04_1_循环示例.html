【例4-9】矩形法

矩形法。将所求的曲边梯形面积划分为若干个同底不同高的小的矩形，求出小矩形的面积之和即为近似的曲边梯形面积。

x变化范围：a~b

x变化步距：h

【例4-10】约分最简分式

分数可以表示为分子/分母的形式。编写一个程序，要求用户输入一个分数，然后将其约分为最简分式。最简分式是指分子和分母不具有可以约分的成分了。如6/12可以被约分为1/2。当分子大于分母时，不需要表达为整数又分数的形式，即11/8还是11/8；而当分子分母相等时，仍然表达为1/1的分数形式。

输入格式

输入在一行中给出一个分数，分子和分母中间以斜杠/分隔，如：12/34表示34分之12。分子和分母都是正整数。

输出格式

在一行中输出这个分数对应的最简分式，格式与输入的相同，即采用分子/分母的形式表示分数。如5/6表示6分之5。

输入样例：66/120 输出样例：11/20
【例4-10】参考代码
#include<stdio.h>
int main(){
    int a,b;    int gcd,r;
    scanf("%d/%d", &a, &b);
    gcd = (a>b)?b:a;   //将较小值设为最大公约数初值
    while(1){
        if(a % gcd == 0 && b % gcd == 0)
            break;      //找到退出
        gcd--;          //没找到，继续试
    }
    printf("%d/%d", a / gcd, b / gcd);
    return 0;
}

【例4-11】求余法（二）
//按求余法转换
#include<stdio.h>
int main(){
  int bin = 0,tem = 0;
  int count = 0;
  //求余时记录位数，避免失去前面的0
  int n,r;
  scanf("%d", &n);
  while(n > 0){
    r = n % 2;
    tem = tem * 10 + r;
    n /= 2;
    count++;
  }
  while(count--){
    bin = bin * 10 + tem % 10;
    tem /= 10;
  }
  printf("%d", bin);
  return 0;
}
【例4-11】按位权转换 · 代码

int main(){
  int n, i = 512;
  int bin = 0, x;
  scanf("%d", &n);
  for(; i >= 1; i /= 2){
    x = n / i;
    bin = bin * 10 + x;
    n -= i * x;
  }
  printf("%d", bin);
  return 0;
}
