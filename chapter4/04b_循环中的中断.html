循环中的中断

第 7 周　break / continue 与素数判定
主讲：孙骏
本节要解决的两个问题
写循环时，几乎都会遇到这两种情况

①答案已经出来了

判断 15 是不是素数，试到 3 就有结论了，可循环还准备把 4、5 … 一路试到 \( \sqrt{x} \)。

②这一轮不想做

输入一串成绩，遇到负数（无效数据）只想跳过这一条，后面的数据还要接着处理。

两个关键字break 结束整个循环；continue 只结束本次循环。名字很像，作用完全不同，今天要彻底分清。
路线先摆出例题（判断素数）→ 学 break → 学 continue → 看两个陷阱 → 最后回到例题，用 break 把它写完。
例题先行：判断素数
素数大于 1、且只能被 1 和它本身整除的整数。2、3、5、7、11、13 都是素数；4、6、9、15 不是。

输入一个大于 2 的整数 x，判断它是不是素数，输出结论。

输入 x人工怎么判输出
172、3、4 都除不尽（\( \sqrt{17}\approx 4.1 \)，试到 4 就够）17 是素数
15试到 \(i=3\)：15 % 3 == 0，这时已经能下结论15 不是素数
盯住"这时"15 试到 3 就定了，还要不要接着试 4、5 …？这一问，就是今天要解决的问题。
试除法：从 2 试到 \( \sqrt{x} \)
思路：拿 2、3、4 … 挨个去试除
  • i 从 2 开始1 能整除任何整数，试它没有意义
  • 只试到 \( \sqrt{x} \)若 \(x=a\times b\) 且 \(a\le b\)，必有 \(a\le\sqrt{x}\)：小因子一定在前半段
  • 见到因子就下结论\(x\bmod i=0\) 时，一定不是素数，后面的 i 全都白试
  • 试完都没有因子说明 \(x\) 只能被 1 和自身整除 → 是素数
为什么到 \( \sqrt{x} \) 就够18 = 2 × 9，小因子 2 ≤ \( \sqrt{18}\approx 4.24 \)；只要 \(x\) 有因子，最小的那个一定不超过 \( \sqrt{x} \)，所以 \( \sqrt{x} \) 之后不必再试。
别漏等号写成 \(i<\sqrt{x}\) 时，49、121 这类完全平方数会漏掉 \(i=\sqrt{x}\) 这个因子，把 49 误判成素数。
卡住的地方：找到因子之后
循环能写出来，结论却"卡"在循环里面
i = 2;
while (i <= sqrt(x)) {
    if (x % i == 0) {
        /* 这里已经能确定：x 不是素数 */
    }
    i++;
}
问题结论已经有了，循环却还要把 i 从 3 一路试到 \( \sqrt{x} \)：15 白跑 2 轮，一个五位数可能要白跑上百轮。
这段循环的流程图
想提前走人循环的出口原本只有"条件变 0"；想在中间离开，C 语言给了两个关键字：break 与 continue。这道例题先放一放，学完两个关键字，最后再回来收尾。
break 语句：形式与功能
一般形式
break;
能出现在哪里
  • switch 的 case 分支里
  • 循环体内部（while / do-while / for）
两条功能
①跳出所在的多分支 switch 语句。
②跳出所在的循环语句——提前结束整个循环，条件不再判断。
三点注意不带任何值（break; 后面不加条件）；只能出现在 switch 或循环体内；它结束的是整个循环，不是这一轮。
break 把控制送到哪里
break：直接跳到循环外面
去向不是"回到循环开头"，也不是"回到上一句"，而是循环后面的第一条语句。
循环就此结束剩下的轮次一次都不执行，循环条件也不再判断。
两条路，一个出口条件变 0 与 break 跳出，最后都落到同一个框——程序不会告诉你它是从哪条路来的。
例：1~5 遇到 3 就停
循环体（完整程序略）
for (i = 1; i <= 5; i++) {
    printf("%d ", i);     /* ① */
    if (i == 3) break;    /* ② */
    printf("%d ", i);     /* ③ */
}
逐轮看
i② 成立？这一轮打印
1不成立1 1
2不成立2 2
3成立 → break3（③ 不执行）
1 1 2 2 3
看清楚i = 4、i = 5 这两轮根本没有发生——不是"跳过了 printf"，而是整个循环已经结束。
追问：break 之后，i 停在几？

break 只把控制送走，变量的值原封不动：本例 i 停在 3；若是正常跑完（条件变 0），i 会是 6。这个"循环终值"就是后面判断素数的依据。

continue 语句：形式与功能
一般形式
continue;
能出现在哪里
  • 循环体内部（while / do-while / for）
  • 不能用在 switch 里替代 break
唯一的功能
核心提前结束本次循环，接着进行"是否执行下次循环"的判断。
循环没结束只是这一轮到此为止：本轮剩下的语句不做了，下一轮照常开始。
和 break 的分水岭break 走的是"整个循环"，continue 走的是"这一轮"。
continue 把控制送回哪里
continue：回到循环的判断处
去向不是"循环外面"，而是回到下一次循环的判断：for 还要先执行 i++。
这一轮到此为止continue 后面的语句本轮不执行，下一轮从头再来。
对比着看break 的箭头往下走（离开循环），continue 的箭头往回走（回到判断）。
同一段程序：break 换成 continue
break 版
for (i = 1; i <= 5; i++) {
    printf("%d ", i);
    if (i == 3) break;
    printf("%d ", i);
}
1 1 2 2 3
continue 版（只改一个词）
for (i = 1; i <= 5; i++) {
    printf("%d ", i);
    if (i == 3) continue;
    printf("%d ", i);
}
1 1 2 2 3 4 4 5 5

break 与 continue 对照
对比项breakcontinue
作用对象整个循环（或整个 switch）只作用于当前这一轮
控制去向循环之后的第一条语句循环"下一次判断"处（for 还要先做 i++）
循环还继续吗不再继续继续，直到条件为 0
能不能用在 switch能，用来结束分支不能（switch 不是循环）
典型用途找到答案就收工、出错就退出跳过非法数据、跳过不关心的元素
记法break 是"散会"，continue 是"你去下一轮"。散会之后谁也不发言，下一轮则还是同一个会议室。
陷阱：for 能直接改成 while 吗
原来：for 版（正确）
sum = 0;
for (n = 0; n < 10; n++) {
    scanf("%d", &m);
    if (m < 0) continue;
    sum = sum + m;
}
改成 while 版（有坑）
sum = 0; n = 0;
while (n < 10) {
    scanf("%d", &m);
    if (m < 0) continue;
    sum = sum + m;
    n++;              /* 被跳过 */
}
后果只要输入一个负数，continue 就把 n++ 跳过去了，n 永远是 0，循环条件永远成立 → 死循环。
原因与改法for 的 n++ 写在循环头里，continue 绕过的是循环体，绕不过循环头；改 while 时要把 n++ 挪到 continue 之前，或用别的写法。
另一种用法：for(;;) 与 break
例：求 1 + 2 + … + 100
sum = 0; i = 1;
for (;;) {               /* 三个表达式全空 */
    if (i > 100) break;  /* 唯一出口 */
    sum += i;
    i++;
}
printf("%d\n", sum);     /* 5050 */
三种写法对照
写法说明
for(i=1;i<=100;i++)三要素齐全，最常用
for(;i<=100;)省略 e1、e3，初值与步进写在别处
for(;;)条件恒成立，只能靠 break 出去
两个分号不能省for(;;) 里两个分号必须都在；写成 for() 是语法错误。
使用场景循环次数事先不知道、只能"做到满足条件为止"时，这种"无条件循环 + break"最自然。

回到素数：算法流程图
找到因子就跳出，跳出即定案
看懂这张图
菱形①\(i\le\sqrt{x}\)：非0 继续试；0 说明已经试完。
菱形②x % i == 0：非0 找到因子，立刻跳出；0 换下一个 i。
菱形③退出后再问一次 \(i\le\sqrt{x}\)：非0 是跳出（有因子）→ 不是素数；0 是试完（无因子）→ 是素数。
回到素数：参考代码
核心片段：循环 + 一句 break + 一句事后判断
for (i = 2; i <= sqrt(x); i++)        /* ① 从 2 试到 √x */
    if (x % i == 0) break;            /* ② 找到因子就跳出 */
if (i <= sqrt(x))                     /* ③ 看 i 停在哪 */
    printf("%d 不是素数\n", x);        /*    跳出来的 */
else
    printf("%d 是素数\n", x);          /*    试完的   */
完整程序还缺什么#include <stdio.h>、#include <math.h>、int x, i; 的声明和 scanf("%d", &x);。
为什么可以省掉花括号循环体只有一条 if 语句，所以 for 后面不带 { }；加与不加都对，初学阶段建议都加上，改起来不容易出错。

看到差别了吗跳出时 \(i\le\sqrt{x}\)，试完时 \(i>\sqrt{x}\)——同一句 i <= sqrt(x)，恰好把两种结束方式分开。
关键一问：凭什么判断是素数
循环结束后，程序并不知道"是怎么结束的"

C 语言不区分"break 跳出"和"条件不成立"这两条出口，它只保留一件事：i 最终是多少。

循环后的 i说明应该输出
\(i\le\sqrt{x}\)被 break 打断，找到了因子不是素数
\(i>\sqrt{x}\)条件自然变 0，全部试完是素数
所以判断语句必须放在循环之后，用 if (i <= sqrt(x)) 再问一次——这正是程序里第 ③ 行的来历。
边界情况输入 2：\(i=2\) 已大于 \( \sqrt{2}\approx 1.41 \)，循环一次都不执行，i 仍是 2 → 判为素数，正确。
易错点清单
  • i 从 1 开始1 能整除任何整数，第一轮就判成"不是素数"，全错
  • 漏 math.h用了 sqrt 却没 #include <math.h>，编译告警或链接失败
  • 漏了等号写成 \(i<\sqrt{x}\)：49、121 这类完全平方数会被误判成素数
  • break 当 return写成 return 0; 会直接结束整个程序，后面的判断不再执行
  • 跳出后不判断只靠"有没有跳出"记状态又没记对，分不清两条出口
  • while 里忘了 i++循环变量不推进，条件永远成立 → 死循环
自查一遍试除范围对不对？出口判断放对位置没有？跳出之后还能不能拿到 i 的值？
小结：三句话

①break

结束整个循环，控制落到循环之后的第一条语句。

②continue

只结束本次循环，回到下一次的判断；for 还会先做 i++。

③事后看变量

跳出与正常结束靠循环变量的终值区分，这是判断素数的关键。

场景用什么例子
答案已确定，不必再跑break找到一个因子就判"不是素数"
这条数据不要，其余照做continue成绩为负，跳过这一条
循环次数事先不知道for(;;) + break一直读到满足条件为止
