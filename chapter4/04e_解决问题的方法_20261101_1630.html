解决问题的方法

自顶向下，逐步求精
主讲：孙骏
核心思想：自顶向下，逐步求精
一句话
核心把要解决的大问题，从最上层（整体目标）出发，一层层往下拆成更小、更容易解决的小问题，直到每个小问题都能直接用代码实现。

①自顶向下

先想整体框架，再填细节，不急着写第一行代码。

②逐步求精

每一步都把“还太粗”的步骤继续细化，直到可编码。

③模块化

每个细化出的小功能，对应一两个语句或一段循环。

本课下面用【例 4-17】走完“细化 → 回溯 → 实现 → 调试 → 优化”五步，再用【习题 7-1】练手。
方法路线图：五步法
从“想清楚”到“跑对跑快”

1细化

把问题拆成顶层步骤。

2回溯

把每个步骤展开成可编码结构。

3实现

写成 C 代码并运行。

4调试

对比预期，找出逻辑漏洞。

5优化

找内在规律，减少冗余计算。

主线【例 4-17】完整演示这五步；【习题 7-1】由你独立用同一套方法完成。
例 4-17·题目
先理解要算什么

求前 n 个“三角形数”之和：

s = 1 + (1+2) + (1+2+3) + … + (1+2+…+n)

示例当 n = 7 时，s = 1 + 3 + 6 + 10 + 15 + 21 + 28 = 84。
思考别急着写循环——先想清楚“每一层在算什么”，下一页开始细化。
例 4-17·细化（N-S 图·一）
第 1 步：把“计算 s”展开为 i 循环（计算 p、s 累加）
说明“计算 p”先作为待细化子块，下一步再展开成 j 循环。
例 4-17·回溯（N-S 图·二）
第 2 步：回溯展开“计算 p” → p=0 与 j 循环
要点每轮 i：先 p=0 清零，j 从 1 累加到 i 得到 1+2+…+i，再把 p 累加到 s。两个循环（i 控制层数、j 在每层累加）就是回溯得到的可编码结构。
例 4-17·实现（C 代码·三）
第 3 步：照上一页结构写出 C 代码（外层 i / 内层 j / s 累加）
#include <stdio.h>
int main(){
    int i, j, p, s=0, n;
    printf("Enter n! \n");
    scanf("%d", &n);
    for(i=1;i<=n;i++){
        p=0;
        for(j=1;j<=i;j++)
            p+=j;
        s+=p;
    }
    printf("s = %d\n", s);
    return 0;
}
Enter n! 7 s = 84
例 4-17·调试（四）
第 4 步：调试——下面代码故意留坑：p 只在循环外初始化一次
#include <stdio.h>
int main(){
    int i, j, p=0, s=0, n;
    printf("Enter n! \n");
    scanf("%d", &n);
    for(i=1;i<=n;i++){
        for(j=1;j<=i;j++)
            p+=j;
        s+=p;
    }
    printf("s = %d\n", s);
    return 0;
}
易错p 只在循环外初始化一次，内层累加的 p 会跨 i 一直累积、没有在每层重新归零 → 结果偏大。正确写法应在 for(i…) 内先把 p=0。
例 4-17·优化（五）
第 5 步：优化——用 p = p + i 递推，省掉整个内层循环
#include <stdio.h>
int main(){
    int i, p, s, n;
    printf("Enter n!\n");
    scanf("%d", &n);
    for(i=1,p=s=0;i<=n;i++){
        p=p+i;   // 不需内层循环
        s=s+p;
    }
    printf("s = %d\n", s);
    return 0;
}
优化点第 i 层的累加和 = 上一层累加和 + i，即 p = p + i，于是内层循环可以整个删掉。
小结：例 4-17 教给我们什么
同一道题，五种收获

先想后写

细化让代码结构在动笔前就清晰。

结构即图表

N-S 图与代码是一一对应的。

把“预期逻辑”和“实际代码”并排看，坑立刻现形。

题目习题 7-1：求 cos x 的近似值（下页给出完整要求）。
习题 7-1·题目
习题 7-1：求 cos x 的近似值

已知 cos x 的泰勒展开：

cos x = 1 − x2/2! + x4/4! − x6/6! + … + (−1)n x2n/(2n)!

输入实数 x（弧度）与整数 n（0≤n≤100）。输出cos(x) 保留小数点后 6 位。
样例输入 1.5 3 → 输出 cos(1.500000)=0.070117。用双精度以保证精度。
习题 7-1·初版与缺陷
初版代码：阶乘用循环逐项相乘
#include <stdio.h>
#include <math.h>
int main(){
    double x,s;
    int i,n,b;
    s=1; b=1;
    scanf("%lf%d",&x,&n);
    for(i=1;i<=n;i++){
        b=1;
        for(j=1;j<=2*i;j++)
            b*=j;
        s=s+pow(-1,i)*pow(x,2*i)/b;
    }
    printf("cos(%.6lf)=%.6lf",x,s);
    return 0;
}
缺陷① b 用 int，200! 远超 int 范围（±231），溢出得错值；② 直接 pow(x,2*n) 在 x、n 较大时同样会超出表示范围。
习题 7-1·解决办法
解决办法：换类型 + 用递推
#include <stdio.h>
#include <math.h>
int main(){
    double x,s,b;
    int i,n;
    s=1; b=1;
    scanf("%lf%d",&x,&n);
    for(i=1;i<=n;i++){
        b=b*2*i*(2*i-1);
        s=s+pow(-1,i)*pow(x,2*i)/b;
    }
    printf("cos(%.6lf)=%.6lf",x,s);
    return 0;
}
修复① b 改为 double，阶乘不再溢出；② 更好的是用递推：第 i 项 ti = ti-1 · (−1)·x² / ((2i−1)·2i)，连 pow 都省掉，最稳。
