案例引入：求圆的面积和周长
问题 已知圆的半径 r，求它的周长 c 和面积 s。（公式：c = 2πr，s = πr²）
/* 求圆的周长和面积 */
#include <stdio.h>
#define PI 3.14          // 符号常量

int main()
{
    double r, c, s;           // 定义变量
    scanf("%lf", &r);        // 输入半径
    c = 2 * PI * r;          // 计算周长
    s = PI * r * r;         // 计算面积
    printf("c=%.2f, s=%.2f\n", c, s);
    return 0;
}
输入：2 ⏎ 输出：c=12.56, s=12.56
本案例涉及的知识点
① 常量：3.14、2、#define PI
② 变量：r、c、s
③ 数据类型：double
④ 标识符：变量名怎么起
⑤ 输入输出：scanf、printf
⑥ 运算符：*、=
⑦ 类型转换：整数 2 与 double 相乘
⑧ 顺序结构：输入 → 计算 → 输出
⑨ 输出格式匹配：%lf、%.2f

常量：程序运行中其值不能改变的量
定义 常量的值是在编译时确定的，程序运行过程中不能被改变。

按定义方式，C 语言的常量分为四类：

📝① 字面量

源代码里直接写出来的值
如 123、3.14、'A'、"Hello"

🏷️② 符号常量

用 #define 给值取一个名字
如 #define PI 3.14

📋③ 枚举常量

批量定义一组命名整数
如 enum { RED, GREEN, BLUE };

🔒④ 只读常量

用 const 修饰，初始化后不可修改
如 const int n = 10;

一句话 字面量是"直接写出来的值"；其余三类都是"给值取的名字"，区别在于怎么取。
字面量的书写形式
类型书写形式示例
整型字面量十进制 / 八进制 / 十六进制3、015、0x0D
实型字面量小数形式 / 指数形式-16.783、3.4e-5
字符字面量单引号括起来的单个字符'A'、'$'、'9'
转义字符反斜杠 + 特定字符'\n'、'\101'
字符串字面量双引号括起来的一串字符"Welcome to C"
注意 八进制以 0 开头，十六进制以 0x 开头；0579 是非法的八进制（含 9）。
符号常量
定义格式
#define 符号常量名 字面量
示例
#define PI 3.1415926
#define MAX 100

int main()
{
    double r = 2.0;
    double area = PI * r * r;   // 用 PI 代替 3.1415926
    return 0;
}
好处 ① 改一处，全局生效；② 名字有意义，可读性好；③ 避免手写多次出错。
约定 符号常量名习惯用大写字母，以便和变量名区分。
枚举常量与只读常量

📋枚举常量

enum Weekday { MON=1, TUE, WED, THU, FRI, SAT, SUN };

· 不写初值时，默认从 0 开始递增
· 可以显式赋初值，后续自动递增
· 相比 #define，有类型，可调试

🔒const 只读常量

const double PI = 3.1415926;

· 有类型，参与类型检查
· 初始化后不能修改
· 调试器能看到名字
· 严格说是"只读变量"

对比 #define PI 3.14 与 const double PI = 3.14; 的区别
#define PI 3.14 是预处理宏，编译器看不到名字；
const double PI = 3.14; 是有类型的只读常量，能参与类型检查。
选择 简单值用 #define 或 const 都行；一组相关整数用 enum。
变量在内存中长什么样

程序运行时，系统为每一个变量分配一个内存单元，并在变量名、内存地址、变量值之间建立一一对应关系。

图：PythonTutor.com 中变量 x 在内存中的地址
三者的角色
① 变量名：变量名就像房间的"客人姓名"，内存地址就像"房间号"。
编译时前台（编译器）登记好"谁住哪间"；运行时程序只关心"访问哪个房间号"，不再需要姓名。
② 内存地址：机器用的门牌号，用十六进制表示
③ 变量值：存在这个地址里的数据，可变的；? 表示未初始化
为什么要分清？
因为后面的 scanf("%d", &n); 里的 &n，取的就是变量 n 的地址。
后面讲指针时，指针就是专门存"地址"的变量。

给变量起名字：标识符命名规则
命名规则
  1. 由字母、数字、下划线组成，必须以字母或下划线开头
  2. 大小写字母是不同字符；不能含有其他字符，不能跨行
  3. 关键字、库函数名不能用作标识符

✅合法标识符

student_name
birthday
age
_count

❌非法标识符

123abc（数字开头）
my name（含空格）
int（关键字）
printf（库函数名）

良好习惯 用单词或简写命名，见名知意。
关键字：C 语言的保留字
定义 关键字是 C 语言中明确的保留字，它们有特定的含义，不能用作标识符。

ANSI C 标准中有 32 个关键字：

autobreakcasecharconstcontinuedefaultdo
doubleelseenumexternfloatforgotoif
intlongregisterreturnshortsignedsizeofstatic
structswitchtypedefunionunsignedvoidvolatilewhile
常见错误 把 int、float、return 当变量名使用，编译器会直接报错。
变量的定义
定义格式
类型定义符 变量名表;

int student_num;
float score, aver;
int n1, n2, total;
规则 变量必须先定义，后使用；同一函数中，变量名不能重复。
建议 通常把变量定义语句集中放在函数的开始处，便于阅读和维护。
变量的初始化
定义的同时赋初值
类型定义符 变量 = 表达式;

long distance = 700000;
double area = 9.6e7;
int n1 = 123, n2 = 456, total;
警告 未赋初值的变量，其值是一个随机数，不是 0。直接使用会导致不可预知的结果。
易错 int a, b, c = 5; 只给 c 赋了初值，a、b 没有初值；
int a = b = c = 5; 是非法写法，b、c 未定义。
变量赋值
赋值运算符 =
变量名 = 表达式;
  • 一个变量可以先后被多次赋值，但只保存最后一次赋的值。
  • 优先级：14（较低）
  • 结合方向：自右向左
int a, b, c;
a = b = c = 5;        // 从右往左：c=5, b=5, a=5
a = b = (c = 5);         // 等价于上面的单步
// (a = b) = c = 5;      // 错误！左边必须是变量
使用变量的注意事项
  • ① 先定义后使用未定义的变量，编译器会直接报错
  • ② 不能重复定义同一函数中，变量名不能重复定义
  • ③ 集中定义（旧标准要求）把变量定义语句集中放在函数开始处，（新标准）用之前定义
  • ④ 未赋初值不确定未赋初值的变量，其值是随机数
让程序说话：printf()
调用格式
printf("格式控制字符串", 输出列表);
格式控制包括
  • 格式说明：以 % 开头，如 %d（整数）、%f（实数）、%c（字符）、%s（字符串）
  • 普通字符：除格式说明符以外的字符，原样输出
  • 转义字符：如 \n 表示换行
头文件 调用 printf 函数时，需要包含 #include <stdio.h>。
printf() 常用格式字符
格式符含义示例与输出
%d十进制整数int a=567; printf("%d",a); → 567
%f小数形式浮点数printf("%f",3.14); → 3.140000
%c单个字符int a=65; printf("%c",a); → A
%s字符串printf("%s","ABC"); → ABC
%x十六进制无符号整数int a=255; printf("%x",a); → ff
%o八进制无符号整数int a=65; printf("%o",a); → 101
%e指数形式浮点数printf("%e",567.789); → 5.677890e+002
必记四件套 %d 整数 · %f 浮点 · %c 字符 · %s 字符串 —— 先记这 4 个，就能应付 90% 的作业。
例：用 printf 输出圆面积周长
题目 已知半径 r = 2.0，计算圆的周长和面积，并输出结果（保留两位小数）。 
#include <stdio.h>
#define PI 3.14

int main()
{
    double r = 2.0;          // 半径直接赋值
    double c, s;
    c = 2 * PI * r;          // 计算周长
    s = PI * r * r;         // 计算面积
    printf("c = %.2f\n", c);
    printf("s = %.2f\n", s);
    return 0;
}
运行结果
c = 12.56 s = 12.56
本题用到
· double 变量定义
· #define 符号常量
· * 乘法运算
· printf("%.2f") 输出2位小数位数
· printf("%f") 默认输出6位小数位数
输入函数 scanf()
调用格式
scanf("格式控制字符串", 地址表列);
  • 格式说明的含义与 printf 相同
  • 地址表列由若干地址组成，各地址之间用逗号分隔
  • 变量地址的表示形式：&变量名（&取地址符，&不能省略）
  • 输入数据时，以回车、Tab、空格相隔
int n1, n2;
scanf("%d", &n1);
scanf("%d", &n2);
输入：123 ⏎ 456 ⏎ 或 ：123 456 ⏎
scanf() 常用格式字符
格式字符说明
%d输入十进制整数
%u输入无符号整数
%o输入八进制整数（非负数）
%x输入十六进制整数（非负数）
%f、%e输入实型数据，double 类型使用 %lf、%le
%c输入单个字符
%s输入字符串
注意 scanf("%2d", &a); 输入2位整数
　　scanf("%.1f", &x);错误！输入时不能指定小数位数
scanf() 注意事项
核心规则 若输入函数中包含普通字符，这些普通字符在输入时必须原样键入。
写法输入示例结果
scanf("%d,%d", &a, &b);3,4a=3, b=4
scanf("%d:%d:%d", &h,&m,&s);12:30:5h=12, m=30, s=5
scanf("a=%d,b=%d", &a,&b);a=12,b=24a=12, b=24
注意 初学阶段，格式串里尽量只写 %d、%f 等格式说明符；
提示信息用 printf 单独输出。printf("a="); scanf("%d",&a);
PTA平台上，不要加任何提示信息！！！
练习一：整数与浮点数的输入输出
目标 巩固 printf、scanf、%d、%f、%lf 的用法。
练习 1：两整数求和
#include <stdio.h>
int main()
{
    int a, b, sum;
    scanf("%d %d", &a, &b);
    sum = a + b;
    printf("sum=%d\n", sum);
    return 0;
}

运行示例：
输入 12 34 → 输出 sum=46

练习 2：两实数求和
#include <stdio.h>
int main()
{
    double x, y, sum;
    scanf("%lf %lf", &x, &y);
    sum = x + y;
    printf("sum=%.2f\n", sum);
    return 0;
}

运行示例：
输入 3.14 2.86 → 输出 sum=6.00

易错点 · double 输入必须用 %lf
· scanf 里变量前必须写 &
