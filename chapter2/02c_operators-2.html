scanf 返回值：判断输入是否成功
定义 scanf 的返回值是一个整数，表示成功读入的数据个数,一个都没读到，返回 0。
读 1 个数
int x;
int n = scanf("%d", &x);
printf("n=%d, x=%d\n", n, x);
输入nx
123⏎1123
abc⏎0原值

读成功 → n=1；
读失败（遇到非数字）→ n=0，x 保持原值。

读 2 个数
int a, b;
int n = scanf("%d%d", &a, &b);
printf("n=%d\n", n);
输入n结果
12 34⏎2a=12, b=34
12,34⏎1a=12, b 原随机值
ab⏎0a、b 都保持原随机值

有几个数读成功，返回值就是几。

scanf 返回值有什么用

核心用途：判断输入是否成功，避免"读失败还用错数据"。

❌不看返回值

int x;
scanf("%d", &x);
printf("x=%d\n", x);

输入 abc 时：
· x 保持原值，通常是随机数
· 但程序毫不知情，继续往下执行
· 输出结果不可预知

✅看返回值

int x;
if (scanf("%d", &x) > 0) {
    printf("读入成功: %d\n", x);
} else {
    printf("输入无效\n");
}

输入 abc 时：
· 返回值是 0，不满足 > 0 的条件
· 程序走 else 分支，提示"输入无效"
· 不会用错数据

为什么需要类型转换

✅类型相同

直接运算，结果类型不变

1 / 2 → 两个 int，结果 0（int）
1.0 / 2.0 → 两个 double，结果 0.5

🔄类型不同

需转换为同一类型再运算

1.0 / 2 → int 转 double，结果 0.5
'a' + 3 → char 转 int，结果 100

核心 C 语言中类型转换有两种方式：隐式转换（自动）和强制转换（手动）。
隐式类型转换（自动）

由编译系统自动完成，程序员无需干预。
方向是：向字节数多（精度高）的类型转换。

规则示例
float → double 表达式中只要有 float，一律先转 double：
5 / 2.0 → 2.5
char → int 字符参与运算用 ASCII 码值：
'a' + 3 → 100
int → double 5.0 / 2 → 2 转 double → 2.5
自动类型转换规则示意图
方向 char/short → int → unsigned → long → double，由低到高自动提升。
混合运算与自动类型转换
自动类型转换 不同类型的数据在运算时，先转换为同类型再运算，由编译系统自动完成。 
char ch = 1;
int i = 1;
float f = 1.5;
double d = 1.3, dd;

dd = (ch / i) + (f * d) + (f + i);
子表达式运算类型结果类型
ch / ichar ÷ int → intint
f * dfloat × double → doubledouble
f + ifloat + int → doubledouble
三项相加int + double + doubledouble
赋给 dddouble → doubledouble
转换方向 char/short → int → unsigned → long → float → double，由低到高。
赋值表达式中的隐式类型转换

原则：右边的值会转换为左边变量的类型。

⬆️低 → 高

整型赋给实型：
值以浮点形式存储，大小不变

int i = 10;
float f = i; → f = 10.0

⚠️高 → 低

实型赋给整型：
直接截断小数部分（不是四舍五入）

int i = 2.56; → i = 2
int i = 2.99; → i = 2

警告 高精度 → 低精度可能丢失信息，使用时要特别小心。
强制类型转换
一般格式
(类型名)(表达式)
示例对比
(double)3 / 2       // 3 先转 double，结果 1.5
(double)(3 / 2)     // 先算 3/2 = 1，再转 double → 1.0

(int)3.6            // 截断小数 → 3
(int)(x + 7.4)      // 先算 x+7.4，再整体截断
(int)x + 7.4        // 先截断 x，再加 7.4
关键 强制转换只改变表达式结果的类型，变量本身的值及类型不会改变。
如 float x = 3.6;，(int)x 之后，x 的值还是 3.6。
强制类型转换的易错点

⚠️易错例一：括号位置决定作用范围 

float x = 3.8;
int a = (int)x + 7.4;      // (int)3.8 = 3，3 + 7.4 = 10.4 → a = 10
int b = (int)(x + 7.4);    // x + 7.4 = 11.2，(int)11.2 = 11 → b = 11

结论：括号的位置决定了强制转换的作用范围。

⚠️易错例二：不改变变量本身的类型 

float x = 2.8;
x = (int)x;             // x 的值变为 2.0，但 x 的类型还是 float
printf("x=%f", x);        // 输出 x=2.000000
把数学表达式写成 C 表达式
数学表达式C 表达式
\(s = \dfrac{1}{xyz}\) s = 1.0 / (x*y*z)
s = 1.0/x/y/z
\(s = \dfrac{1}{4}\left(x^2 + y^{-3}\right)\) s = 0.25*(x*x + 1.0/y/y/y)
\(\dfrac{\tan x + \cot x}{\sin x + \cos x}\) (tan(x) + 1/tan(x)) / (sin(x) + cos(x))
注意：x 是弧度，不是角度
\(\sqrt{\dfrac{e^x}{y - 2}}\) sqrt(exp(x) / (y-2))
易错写法 s = 0.25(x*x + 1.0/y/y/y) —— 缺少乘号 *，C 语言不会自动补乘号。也不要用 · 哦！
使用数学函数需注意 ① 必须写 #include <math.h>； ② 参数个数、类型、顺序、单位要正确； ③ 注意函数返回值的类型和单位。
格式符与数据类型必须匹配
警告 printf / scanf 中，如果格式符与变量类型不一致，变量将得不到正确的数据，或输出结果错误。
错误写法 原因
printf("%d", 6 * fabs(-4)); fabs() 返回 double，应用 %f
printf("%f", 6 * abs(-4)); abs() 返回 int，应用 %d
double d; scanf("%f", &d); （d 是 double类型） double 必须用 %lf
float x; scanf("%d", &x); （x 是 float类型） float 必须用 %f
养成习惯 写代码时，时刻问自己：这个数据是什么类型？应该以什么格式输入输出？
字符输入输出：getchar() 与 putchar()

⌨️getchar()　字符输入

ch = getchar();
等价于 scanf("%c", &ch);

🖨️putchar()　字符输出

putchar(ch);
等价于 printf("%c", ch);

示例 1：getchar 读取字符
#include <stdio.h>

int main()
{
    char ch;
    ch = getchar();      // 读取一个字符
    printf("%c", ch);    // 输出该字符   
    return 0;
}
说明: getchar() 从键盘接收一个字符，必须按回车才结束读取。
　　　getchar() 返回值为从键盘接收到的字符。
示例 2：putchar 的三种写法
#include <stdio.h>

int main()
{
    putchar(65);        // 输出 'A'（ASCII 65）
    putchar('A');      // 输出 'A'
    putchar('a'-32);   // 输出 'A'
    return 0;
}
运行结果 AAA —— 三种写法，结果都是字符 A。
字符与整数的混合运算
字符可以直接参与算术运算
char ch = 'A';
int result = ch + 10;        // 65 + 10 = 75
printf("%c", result);        // 输出 'K' (ASCII 75)

🔁大小写转换

大写转小写：ch = ch + 32;
小写转大写：ch = ch - 32;

🔢数字字符 ↔ 数字

字符转数字：int num = ch - '0';
数字转字符：char ch = num + '0';

应用 把字符 '8'、'5'、'2'、'0' 拼成整数 8520：
value = (d1-'0')*1000 + (d2-'0')*100 + (d3-'0')*10 + (d4-'0');
连续读 3 个字符：空格和回车也是字符
注意 用 %c 读字符时，空格、回车、Tab 都是有效字符，会被原样读入。 
#include <stdio.h>

int main()
{
    char a, b, c;
    scanf("%c%c%c", &a, &b, &c);
    printf("[%c][%c][%c]\n", a, b, c);
    return 0;
}
三种输入方式对照
输入输出
ABC⏎ [A][B][C] ✅
A B C⏎ [A][ ][B] ❌
A⏎ B⏎ [A][⏎][B] ❌
结论 想读入 A、B、C 三个字符， 必须连续输入 ABC，中间不能加空格或回车。
输入"三位整数"：写法对比
题目 输入一个三位整数 123，求各位数字之和 → 6

✅ 读整数 + 拆分
（正确写法，推荐） 

int x, a, b, c;
scanf("%d", &x);
a = x / 100;
b = x / 10 % 10;
c = x % 10;
printf("%d", a+b+c);

输入：123⏎　　　 输出：6 ✅

与题目"输入一个三位整数"格式完全一致

❌ 输入三个整数
（错误写法） 

int a, b, c;
scanf("%d%d%d", &a, &b, &c);
printf("%d", a+b+c);

输入：1 2 3⏎
输出：6

格式与题目不符，
题目要求输入"一个整数"，输入时必须加空格

结论 题目说"输入一个三位整数"，就要用 scanf("%d", &x); 读入，再用 / 和 % 拆分。
输入格式必须与题目要求完全一致，否则自动评测会判错。
输入"三位整数"的两种投机写法
投机 "投机"指能通过自动评测，但算法上不推荐（如格式特殊、可读性差、不通用等）。

⚠️ 输入三个字符
（能过，但算法不推荐） 

char a, b, c;
scanf("%c%c%c", &a, &b, &c);
printf("%d", a+b+c-3*'0');

输入：123⏎
读到 '1' '2' '3'

把整数当字符处理，需手动转数字，
可读性差，不推荐

⚠️ %1d 逐位读
（能过，但算法不推荐） 

int a, b, c;
scanf("%1d%1d%1d", &a, &b, &c);
printf("%d", a+b+c);

输入：123⏎
输出：6

依赖 %1d 的宽度限定，
代码不通用，不推荐

结论 这两种写法虽然能通过平台评测，但算法上不推荐，实际工程中建议使用上一页的正规写法。
输入缓冲区问题：一个经典 Bug
// 问题代码（有 Bug）
int choice;
char confirm;

printf("请输入您的选择（1-3）：");
scanf("%d", &choice);

printf("确认继续吗？(y/n)：");
confirm = getchar();    // ← 这里读到的是回车符！
为什么会这样

输入整数后按回车，回车符留在缓冲区；
紧接着的 getchar() 直接读走这个回车符，
而不是等用户输入 y 或 n。

解决方法
① 在 getchar() 前加一个 getchar(); 吃掉回车；
② 用 scanf(" %c", &ch);（%c 前加空格）跳过前面所有空白字符。
③ 用 scanf("%d ", &choice);（%d 后加空格也可以）表示忽略整数之后的所有空白字符。
　　 getchar();　读取空白字符后输入的第一个非空白字符。

练习 1：大写字母转小写

场景：输入一个大写字母，输出对应的小写字母。 

#include <stdio.h>
int main()
{
    char ch;
    ch = getchar();

练习 2：字符拼整数

场景：输入 3 个数字字符，拼成一个 3 位整数。 

#include <stdio.h>
int main(){
    char d1, d2, d3;
    int value;
    scanf("%c%c%c", &d1, &d2, &d3);
    value = (d1 - '0') * 100
          + (d2 - '0') * 10
          + (d3 - '0');  // ← 字符转数字'1' - '0' = 1
    printf("value = %d\n", value);
    return 0;
}

输入：123⏎ 　　　输出：value = 123

易错点:　 ① %c 不跳过空格，连续输入不能加分隔符；　　　 ② 字符参与运算时用的是 ASCII 码，不是字符本身；
　　　　 ③ 字符转数字的标准写法:'1' - '0' = 1。

顺序结构示例：求圆的面积和周长

算法分析
  1. 输入半径 r（double）
  2. 计算周长 c = 2πr
  3. 计算面积 s = πr²
  4. 输出 c 和 s
#include <stdio.h>
#define PI 3.14

int main()
{
    double r, c, s;
    scanf("%lf", &r);
    c = 2 * PI * r;
    s = PI * r * r;
    printf("c=%lf,s=%lf\n", c, s);
    return 0;
}
要点:　 ① 分析清楚输入量、输出量；　　② 按"输入 → 计算 → 输出"顺序写；　　③ 用符号常量 PI 便于修改。
顺序结构示例：已知 \(y = \left|1 - x^{3.6}\right|\)，输入 x，求 y
#include <stdio.h>
#include <math.h>

int main()
{
    double x, y;
    scanf("%lf", &x);
    y = fabs(1 - pow(x, 3.6));
    printf("y=%.3f\n", y);
    return 0;
}

要点
  • 用数学函数需 #include <math.h>
  • 确定x，y的数据类型为double:　double x,y;
  • 求 x 的 3.6 次幂:　pow(x, 3.6)
  • 对浮点数求绝对值:　fabs()
  • %.3f 输出保留 3 位小数
顺序结构示例：已知三边求三角形面积
#include <stdio.h>
#include <math.h>

int main()
{
    float a, b, c, s, area;
    a = 3; b = 4; c = 6;
    s = 1.0/2 * (a + b + c);
    area = sqrt(s*(s-a)*(s-b)*(s-c));
    printf("area=%.2f\n", area);
    return 0;
}
要点
  • 海伦公式：
    \[ \text{area} = \sqrt{s(s-a)(s-b)(s-c)} \] 其中 \( s = \dfrac{a+b+c}{2} \)
  • 1.0/2 保证结果是实数，切记不能写成1/2
  • sqrt() 求平方根，需要 math.h
