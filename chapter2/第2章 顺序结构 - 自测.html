一、选择题

1. 以下关于常量的叙述中，正确的是（　　）。

A. 常量的值在程序运行过程中可以被改变

B. 常量的类型是显式说明的

C. 常量的值是在编译时给定的，程序运行过程中不能被改变

D. 常量不需要说明类型

查看答案与解析

答案：C

解析：常量的值是在编译时给定的，程序运行过程中不能被改变；常量的类型是隐式说明的，通过书写形式确定。

2. 以下变量名中，合法的是（　　）。

A. 2y　　B. M?m　　C. _M　　D. integer@2

查看答案与解析

答案：C

解析：标识符由字母、数字、下划线组成，必须以字母或下划线开头。A 以数字开头，B 含 ?，D 含 @，均非法。

3. 以下标识符中，不能用作变量名的是（　　）。

A. student_name　　B. int　　C. year　　D. _M

查看答案与解析

答案：B

解析：int 是 C 语言的关键字，不能用作标识符。

4. 以下关于变量的叙述中，错误的是（　　）。

A. 变量必须先定义后使用

B. 在一个函数中，变量名不能重复定义

C. 定义变量时若没有赋初值，则该变量的值自动为 0

D. 通常把定义变量的语句集中放在函数的开始处

查看答案与解析

答案：C

解析：在函数中定义变量时，若没有赋初值，则该变量的值不确定，并不是自动为 0。

5. 以下关于 scanf 的叙述中，正确的是（　　）。

A. scanf 中的变量名前必须加 &

B. scanf 中的普通字符可以随意省略

C. double 类型数据在 scanf 中使用 %f

D. scanf 中可以使用 %.1f 精确控制输入精度

查看答案与解析

答案：A

解析：scanf 中的变量名前必须加 &（数组名除外）；普通字符必须原样输入，不能随意省略；double 类型数据在 scanf 中使用 %lf；scanf 中不建议使用辅助格式符。

6. 以下关于 printf 的叙述中，错误的是（　　）。

A. %d 用于输出十进制整数

B. %8.2f 表示输出宽度为 8，小数位为 2 的实数

C. %c 用于输出单个字符

D. %s 用于输出整型数据

查看答案与解析

答案：D

解析：%s 用于输出字符串，不是整型数据。

四、简答题

1. 简述常量与变量的区别。

查看参考答案
  • 常量：值在编译时给定，程序运行过程中不能被改变；类型是隐式说明的，通过书写形式确定。
  • 变量：程序运行过程中其值可以被改变；类型是显式说明的，通过定义语句确定变量名及其类型。
  • 程序运行时，系统为每一个变量分配一个内存单元，并在变量名和该内存单元地址间建立一一对应的关系。

2. 简述变量的命名规则（标识符规则）。

查看参考答案
  1. 标识符由字母、数字、下划线组成，必须以字母或下划线开头。
  2. 大写字母和小写字母被认为是不同的字符，不能含有其他字符，不能跨行书写。
  3. 关键字、库函数名（如 printf、scanf）不能用来作为标识符。

3. 简述使用变量时应注意的事项。

查看参考答案
  1. 在使用变量时，应注意"先定义，后使用"的原则。
  2. 在一个函数中，变量名不能重复定义。
  3. 除非有特定的需要，通常把定义变量的语句集中放在函数的开始处。
  4. 通常，在函数中定义变量时，若没有赋初值，则该变量的值不确定。

4. scanf 和 printf 中常用的格式字符有哪些？各有什么作用？

查看参考答案

五、编程题

1. 编写程序，输入两个整数，输出它们的和、差、积、商。

查看参考答案 
#include <stdio.h>

int main()
{
    int a, b;
    scanf("%d%d", &a, &b);
    printf("和 = %d\n", a + b);
    printf("差 = %d\n", a - b);
    printf("积 = %d\n", a * b);
    printf("商 = %d\n", a / b);
    return 0;
}

说明：整数除法结果仍为整数，若需得到小数结果，可将变量定义为 float 或 double。

2. 编写程序，输入圆的半径，计算并输出圆的面积和周长（π 取 3.1415926）。

查看参考答案 
#include <stdio.h>
#define PI 3.1415926

int main()
{
    double r, area, perimeter;
    scanf("%lf", &r);
    area = PI * r * r;
    perimeter = 2 * PI * r;
    printf("面积 = %.4f\n", area);
    printf("周长 = %.4f\n", perimeter);
    return 0;
}
