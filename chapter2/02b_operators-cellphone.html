整数除法与求余：最易错的两个运算符

⚠️ / 整除

两整数相除，结果仍为整数

5 / 2 = 2
-5 / 2.0 = -2.5

一旦有一边是实数，结果就是实数

⚠️ % 求余

只有两边都是整数才能求余

5 % 2 = 1
-5 % 2 = -1
5.5 % 2 ← 非法

int num = 123;
int a, b, c;
a = num % 10;         // 个位：3
b = num / 10 % 10;      // 十位：2
c = num / 100;           // 百位：1
求余 % 的符号规则
核心规则 余数的符号与被余数（左操作数）的符号相同。
表达式结果符号来源
15 % 114+（左）
-15 % 11-4−（左）
15 % -114+（左）
-15 % -11-4−（左）
记忆口诀 余数的符号，看左边数的符号。
复合赋值运算符
运算符表达式等价于
+=a += 3a = a + 3
-=a -= 4a = a - 4
*=a *= 9a = a * 9
/=a /= 5a = a / 5
%=a %= 6a = a % 6
 
int a = 12;
a += a -= a * a;
// ① a = a - a*a  → a = 12 - 144 = -132
// ② a = a + (-132) → a = -264
说明 所有赋值运算符的优先级相同，结合方向从右向左；
算术运算符的优先级高于赋值运算符，a *= 3 + 2 等价于 a = a * (3 + 2)。
自增、自减运算符 ++、--

作用：使变量值加 1 或减 1。

➡️ 前置 ++i / --i

先执行 i+1 或 i-1，再使用 i 的值

j=3; k=++j; → k=4, j=4

⬅️ 后置 i++ / i--

先使用 i 的值，再执行 i+1 或 i-1

j=3; k=j++; → k=3, j=4

int a = 3, b = 5, c;
c = (++a) * b;    // a先变4，c = 4 * 5 = 20
a = 3;
c = (a++) * b;    // c = 3 * 5 = 15，然后 a 变 4
注意 ++ / -- 只能用于变量，不能用于常量或表达式： 5++、(a+b)++ 都是非法。
逗号运算符和逗号表达式
格式
表达式1, 表达式2, ..., 表达式n
  • 优先级最低（15），结合方向 从左至右
  • 执行时依次计算各表达式的值
  • 整个逗号表达式的值 = 表达式 n 的值
int a;
a = 3*5, a*4, a+5;      // a = 15，表达式的值为 20

int x, y = 7;
float z = 4;
x = (y = y + 6, y / z);   // y=13, 13/4.0=3.25, x=3
注意：逗号运算符 vs 逗号分隔符
逗号运算符逗号分隔符
x = (a=3, 6*a); printf("%d,%d", a, b);
连接两个表达式，有运算含义 分隔参数，只是标点
表达式的一部分，产生一个值 函数调用的参数列表
int a;
a = (3, 5); → a = 5		 int a, b, c; → 声明三个变量
区分方法 看它出现在哪里：
· 在 ( ) 里、= 的右边，是运算符
· 在声明、参数列表中，是分隔符
sizeof 运算符
两种格式
sizeof(类型定义符)
sizeof(表达式)

功能：返回各种数据类型或表达式所占的字节数。

表达式值
sizeof(char)1
sizeof(int)4（多数编译器）
sizeof(float)4
sizeof(double)8
sizeof('a' + 2)4（char 提升为 int）
sizeof 的使用示例
#include <stdio.h>

int main()
{
    float f;
    int a;
    printf("%d\n", sizeof(f));        // 输出 4
    printf("%d\n", sizeof(char));     // 输出 1
    printf("%d\n", sizeof(a + 2));    // a+2 为 int，输出 4
    printf("%d\n", sizeof(2.5));       // 2.5 为 double，输出 8
    return 0;
}
常见用途 · 计算数组长度：sizeof(arr) / sizeof(arr[0])（第 5 章）
· 判断本机 int、long 等类型占用的字节数
· 内存分配时确定大小（第 7 章）
观察 sizeof 是运算符，不是函数。 它的参数在编译时求值，不产生运行时开销。
练习二（1）：求两整数的商和余数
目标 巩固 /、%、整除与取余的用法。 
#include <stdio.h>
int main()
{
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d / %d = %d\n", a, b, a / b);
    printf("%d %% %d = %d\n", a, b, a % b);
    return 0;
}
运行示例
输入：17 5 输出：17 / 5 = 3 17 % 5 = 2
关键点 · / 整除：结果舍去小数部分
· % 求余：只能用于整数
· 输出 % 本身要写成 %%
易错 5 / 2 = 2（不是 2.5）； 若想得到 2.5，写成 5.0 / 2 或 (double)5 / 2。
练习二（2）：求三位整数各位数字之和
题目 输入一个三位正整数，分别求它的百位、十位、个位，输出三个数字之和。

❌ 错误写法：输入三个整数

int a, b, c;
scanf("%d%d%d", &a, &b, &c);
printf("%d", a + b + c);
输入：1 2 3⏎ 输出：6

按 scanf 写法，输入时三个数之间必须有空格或回车——与输入格式要求不匹配。

✅ 正确写法：输入一个三位整数

int x, a, b, c;
scanf("%d", &x);
a = x / 100;          // 百位
b = x / 10 % 10;       // 十位
c = x % 10;            // 个位
printf("%d\n", a + b + c);
输入：123⏎ 输出：6

结论 读题目时，要看清输入格式：
题目说"输入一个三位整数"，就必须写 scanf("%d", &x);，不能写成三个 %d。
scanf 返回值：判断输入是否成功
定义 scanf 的返回值是一个整数，表示成功读入的数据个数，一个都没读到返回 0。
读 1 个数
int x;
int n = scanf("%d", &x);
printf("n=%d, x=%d\n", n, x);
输入nx
123⏎1123
abc⏎0原值

读成功 → n=1；读失败（遇到非数字）→ n=0，x 保持原值。

读 2 个数
int a, b;
int n = scanf("%d%d", &a, &b);
printf("n=%d\n", n);
输入n结果
12 34⏎2a=12, b=34
12⏎1a=12, b 原值
ab⏎0a、b 都保持原值

有几个数读成功，返回值就是几。

scanf 返回值有什么用

核心用途：判断输入是否成功，避免"读失败还用错数据"。

❌ 不看返回值

int x;
scanf("%d", &x);
printf("x=%d\n", x);
输入 abc 时：
· x 保持原值，通常是随机数
· 但程序毫不知情，继续往下执行
· 输出结果不可预知

✅ 看返回值

int x;
if (scanf("%d", &x) == 1) {
    printf("读入成功: %d\n", x);
} else {
    printf("输入无效\n");
}
输入 abc 时：
· 返回值是 0，不满足 == 1
· 程序走 else 分支，提示"输入无效"
· 不会用错数据

为什么需要类型转换

✅ 类型相同

直接运算，结果类型不变

1 / 2 → 两个 int，结果 0（int）
1.0 / 2.0 → 两个 double，结果 0.5

🔄 类型不同

需转换为同一类型再运算

1.0 / 2 → int 转 double，结果 0.5
'a' + 3 → char 转 int，结果 100

核心 C 语言中类型转换有两种方式：隐式转换（自动）和强制转换（手动）。
隐式类型转换（自动）

由编译系统自动完成，程序员无需干预。方向是：向字节数多（精度高）的类型转换。

规则示例
float → double 表达式中只要有 float，一律先转 double：
5 / 2.0 → 2.5
char → int 字符参与运算用 ASCII 码值：
'a' + 3 → 100
int → double 5.0 / 2 → 2 转 double → 2.5
方向 char/short → int → unsigned → long → double，由低到高自动提升。
混合运算与自动类型转换
自动类型转换 不同类型的数据在运算时，先转换为同类型再运算，由编译系统自动完成。 
char ch = 1;
int i = 1;
float f = 1.5;
double d = 1.3, dd;

dd = (ch / i) + (f * d) + (f + i);
子表达式运算类型结果类型
ch / ichar ÷ int → intint
f * dfloat × double → doubledouble
f + ifloat + int → doubledouble
三项相加int + double + doubledouble
赋给 dddouble → doubledouble
转换方向 char/short → int → unsigned → long → float → double，由低到高。
赋值表达式中的隐式类型转换

原则：右边的值会转换为左边变量的类型。

⬆️ 低 → 高

整型赋给实型：
值以浮点形式存储，大小不变

int i = 10;
float f = i; → f = 10.0

⚠️ 高 → 低

实型赋给整型：
直接截断小数部分（不是四舍五入）

int i = 2.56; → i = 2
int i = 2.99; → i = 2

警告 高精度 → 低精度可能丢失信息，使用时要特别小心。
强制类型转换
一般格式
(类型名)(表达式)
示例对比
(double)3 / 2       // 3 先转 double，结果 1.5
(double)(3 / 2)     // 先算 3/2 = 1，再转 double → 1.0

(int)3.6            // 截断小数 → 3
(int)(x + 7.4)      // 先算 x+7.4，再整体截断
(int)x + 7.4        // 先截断 x，再加 7.4
关键 强制转换只改变表达式结果的类型，变量本身的值及类型不会改变。
如 float x = 3.6;，(int)x 之后，x 的值还是 3.6。
强制类型转换的易错点

⚠️ 易错例一：括号位置决定作用范围

float x = 3.8;
int a = (int)x + 7.4;      // (int)3.8 = 3，3 + 7.4 = 10.4 → a = 10
int b = (int)(x + 7.4);    // x + 7.4 = 11.2，(int)11.2 = 11 → b = 11

结论：括号的位置决定了强制转换的作用范围。

⚠️ 易错例二：不改变变量本身的类型

float x = 2.8;
x = (int)x;             // x 的值变为 2.0，但 x 的类型还是 float
printf("x=%f", x);        // 输出 x=2.000000
把数学表达式写成 C 表达式
数学表达式C 表达式
\(s = \dfrac{1}{xyz}\) s = 1.0 / (x*y*z)
s = 1.0/x/y/z
\(s = \dfrac{1}{4}\left(x^2 + y^{-3}\right)\) s = 0.25*(x*x + 1.0/y/y/y)
\(\dfrac{\tan x + \cot x}{\sin x + \cos x}\) (tan(x) + 1/tan(x)) / (sin(x) + cos(x))
注意：x 是弧度，不是角度
\(\sqrt{\dfrac{e^x}{y - 2}}\) sqrt(exp(x) / (y-2))
易错写法 s = 0.25(x*x + 1.0/y/y/y) ✗ —— 缺少乘号 *，C 语言不会自动补乘号。
使用数学函数需注意 ① 必须写 #include <math.h>；
② 参数个数、类型、单位要正确；
③ 注意函数返回值的类型和单位。
格式符与数据类型必须匹配
警告 printf / scanf 中，如果格式符与变量类型不一致，变量将得不到正确的数据，或输出结果错误。
错误写法原因
printf("%d", 6 * fabs(-4)); fabs() 返回 double，应用 %f
printf("%f", 6 * abs(-4)); abs() 返回 int，应用 %d
scanf("%f", &d);（d 是 double） double 必须用 %lf
scanf("%d", &x);（x 是 float） float 必须用 %f
养成习惯 写代码时，时刻问自己：这个数据是什么类型？应该以什么格式输入输出？
字符输入输出：getchar() 与 putchar()

⌨️ getchar()　字符输入

ch = getchar();
等价于 scanf("%c", &ch);

🖨️ putchar()　字符输出

putchar(ch);
等价于 printf("%c", ch);

示例：putchar 的三种写法
#include <stdio.h>

int main()
{
    putchar(65);        // 输出字符 'A'（ASCII 65）
    putchar('A');      // 输出字符 'A'
    putchar('a'-32);   // 输出字符 'A'（小写转大写）
    return 0;
}
运行结果
AAA
观察 65、'A'、'a'-32 三种写法，结果都是字符 A。
字符与整数的混合运算
字符可以直接参与算术运算
char ch = 'A';
int result = ch + 10;      // 65 + 10 = 75
printf("%c", result);        // 输出 'K' (ASCII 75)

🔁 大小写转换

大写转小写：ch = ch + 32;
小写转大写：ch = ch - 32;

🔢 数字字符 ↔ 数字

字符转数字：int num = ch - '0';
数字转字符：char ch = num + '0';

应用 把字符 '8'、'5'、'2'、'0' 拼成整数 8520：
value = (d1-'0')*1000 + (d2-'0')*100 + (d3-'0')*10 + (d4-'0');
连续读 3 个字符：空格和回车也是字符
注意 用 %c 读字符时，空格、回车、Tab 都是有效字符，会被原样读入。 
#include <stdio.h>

int main()
{
    char a, b, c;
    scanf("%c%c%c", &a, &b, &c);
    printf("[%c][%c][%c]\n", a, b, c);
    return 0;
}
三种输入方式对照
输入输出
ABC⏎ [A][B][C] ✅
A B C⏎ [A][ ][B] ❌
A⏎ B⏎ [A][⏎][B] ❌
结论 想读入 A、B、C 三个字符， 必须连续输入 ABC，中间不能加空格或回车。
输入"三位整数"的四种写法对比
题目 输入一个三位整数 123，求各位数字之和 → 6

✅ 读整数 + 拆分（推荐）

int x, a, b, c;
scanf("%d", &x);
a = x / 100;
b = x / 10 % 10;
c = x % 10;
printf("%d", a+b+c);

输入：123⏎　输出：6 ✅
与题目格式一致

❌ 输入三个整数（不推荐）

int a, b, c;
scanf("%d%d%d", &a, &b, &c);
printf("%d", a+b+c);

输入：1 2 3⏎　输出：6
格式与题目不符

❌ 输入三个字符（不推荐）

char a, b, c;
scanf("%c%c%c", &a, &b, &c);
printf("%d", a+b+c-3*'0');

输入：123⏎
读到 '1' '2' '3'，需要转换

⚠️ %1d 逐位读（非标准）

int a, b, c;
scanf("%1d%1d%1d", &a, &b, &c);
printf("%d", a+b+c);

输入：123⏎　输出：6
非通用写法，不推荐

结论 题目说"输入一个三位整数"，就要用 scanf("%d", &x); 读入，再用 / 和 % 拆分。 输入格式必须与题目要求完全一致，否则自动评测会判错。
输入缓冲区问题：一个经典 Bug
// 问题代码（有 Bug）
int choice;
char confirm;

printf("请输入您的选择（1-3）：");
scanf("%d", &choice);

printf("确认继续吗？(y/n)：");
confirm = getchar();    // ← 这里读到的是回车符！
为什么会这样

输入整数后按回车，回车符留在缓冲区；
紧接着的 getchar() 直接读走这个回车符，
而不是等用户输入 y 或 n。

解决方法 ① 在 getchar() 前加一个 getchar(); 吃掉回车；
② 用 scanf(" %c", &ch);（%c 前加空格）跳过前面所有空白字符；
③ 用 scanf("%d\n", &choice);（%d 后加空格）表示忽略整数之后的所有空白字符。
练习三：字符处理

练习 1：大写字母转小写

场景：输入一个大写字母，输出对应的小写字母。

#include <stdio.h>
int main()
{
    char ch;
    ch = getchar();
    putchar(ch + 32);     // 大写转小写
    putchar('\n');
    return 0;
}

输入：A⏎　输出：a

关键：'A' = 65，'a' = 97，差值恰好是 32。

练习 2：字符拼整数

场景：输入 3 个数字字符，拼成一个 3 位整数。

#include <stdio.h>
int main()
{
    char d1, d2, d3;
    int value;
    scanf("%c%c%c", &d1, &d2, &d3);
    value = (d1 - '0') * 100
          + (d2 - '0') * 10
          + (d3 - '0');
    printf("value = %d\n", value);
    return 0;
}

输入：123⏎　输出：value = 123

关键：'1' - '0' = 1，字符转数字。

易错点 · %c 不跳过空格，连续输入不能加分隔符；
· 字符参与运算时用的是 ASCII 码，不是字符本身；
· '1' - '0' = 1，这是字符转数字的标准写法。

顺序结构例：求圆的面积和周长
算法分析
  1. 输入半径 r（double）
  2. 计算周长 c = 2πr
  3. 计算面积 s = πr²
  4. 输出 c 和 s
#include <stdio.h>
#define PI 3.14

int main()
{
    double r, c, s;
    scanf("%lf", &r);
    c = 2 * PI * r;
    s = PI * r * r;
    printf("c=%lf,s=%lf\n", c, s);
    return 0;
}
要点 ① 分析清楚输入量、输出量；② 按"输入 → 计算 → 输出"顺序写；③ 用符号常量 PI 便于修改。
顺序结构例：已知 \(y = \left|1 - x^{3.6}\right|\)，输入 x，求 y
#include <stdio.h>
#include <math.h>

int main()
{
    double x, y;
    scanf("%lf", &x);
    y = fabs(1 - pow(x, 3.6));
    printf("y=%.3f\n", y);
    return 0;
}
要点
  • 用数学函数需 #include <math.h>
  • pow(x, 3.6) 求 x 的 3.6 次幂
  • fabs() 对浮点数求绝对值
  • %.3f 输出保留 3 位小数
顺序结构例：已知三边求三角形面积
#include <stdio.h>
#include <math.h>

int main()
{
    float a, b, c, s, area;
    a = 3; b = 4; c = 6;
    s = 1.0/2 * (a + b + c);
    area = sqrt(s*(s-a)*(s-b)*(s-c));
    printf("area=%.2f\n", area);
    return 0;
}
要点
  • 海伦公式：
    \[ \text{area} = \sqrt{s(s-a)(s-b)(s-c)} \] 其中 \( s = \dfrac{a+b+c}{2} \)
  • 1.0/2 保证结果是实数，切记不能写成 1/2
  • sqrt() 求平方根，需要 math.h
