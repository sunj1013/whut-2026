【例 5-1】求平均分
题目某组 10 人刚结束 C 语言期中考试，需要统计本组学员的平均分，以及高于平均分的人数。
先解决第一个子问题：求平均分
float score, sum=0, aver;
for(i=1; i<=10; i++){
    scanf("%f", &score);
    sum += score;
}
aver = sum/10;
留下的问题用简单变量 score 累加可以求出平均分，但输入结束后只留下最后一个成绩。
【例 5-1】求高于平均分的人数
第二个子问题要统计高于平均分的人数，必须把 10 个成绩逐一与 aver 比较。
卡在哪里变量 score 是简单变量，只能存储最后一个学员的成绩。
① 10 个学员的成绩与平均分的比较方法

✕ 办法一：重新输入

计算完平均分后，再让学员把成绩重新输入一遍，输入的同时与平均分比较。若学员人数较多，工作量翻倍，明显减慢计算速度。

✕ 办法二：10 个独立变量

设置 score1、score2 …… score10 共 10 个变量。此时不能使用循环，只能逐个处理；若人数改变，同一段代码就无法复用。

② 症结简单变量一次只能存一个值；而本问题需要一次性保存一批同类型数据并反复使用——这正是「数组」要解决的场景。
解决办法：引入"数组"
思路需求是「一次输入、多次使用」：成绩输入一次之后，还要能反复取出来比较。
解决办法引入构造数据类型——数组：把 10 个成绩连续存放在一组同名变量中，再统一与平均分比较。
// 10 个 double 成绩，统一名叫 score
double score[10];
for(i=0; i<10; i++)
    scanf("%lf", &score[i]);
结果一次输入，全部保留，可反复使用。

用变量定义数组长度，三条限制

③ 数组大小数组一旦定义，大小就不能再改变——无论用常量还是变量定义。

获取数组元素的值
两条途径
途径一：初始化在定义数组时对全部或部分元素赋值。
途径二：语句中赋值或输入在语句中为元素赋值或输入——通常利用循环语句。
共同点无论哪条途径，都用 数组名[下标] 定位到一个元素。
例 5-2　利用循环输入数组元素
要求输入时以空格分隔数据；输出时以逗号分隔，末尾没有多余符号。
输入：7 10 27 22 16 输出：7,10,27,22,16
【例 5-2】代码
#include <stdio.h>
int main(void)
{
    int i, a[5];
    // 输入 5 个整数，以空格分隔
    for(i=0; i<5; i++)
        scanf("%d", &a[i]);
    // 前 4 个带逗号；循环到 i<4 为止
    for(i=0; i<4; i++)
        printf("%d,", a[i]);
    // 循环结束时 i 正好是 4，单独输出最后一个
    printf("%d", a[i]);
    return 0;
}

【例 5-3】代码
#include <stdio.h>
int main(void)
{
    int i, a[10];
    for(i=0; i<10; i++)
        scanf("%d", &a[i]);    // 输入
    for(i=0; i<10; i++)
        printf("%4d", a[i]);    // 顺序输出
    printf("\n");
    for(i=9; i>=0; i--)
        printf("%4d", a[i]);    // 逆序输出
    return 0;
}

回到引例统计 10 人平均分与高于平均分的人数——这次用数组把成绩全部留住。
数据分析设置一个包含 10 个 double 类型变量的数组 score，存储所有学员的成绩。
double score[10];
四步算法
  • 定义数组；
  • 输入成绩，同时累加求和；
  • 计算平均成绩；
  • 利用循环，统计高于平均分的人数。
【例 5-4】算法流程图
算法要点
  • ① 第一个循环：边输入边累加，10 个成绩全部留在 score[0] ~ score[9]；
  • ② aver = sum / 10；
  • ③ 第二个循环：再用同一批成绩逐个与 aver 比较，统计人数。
数组的价值：一次输入、多次使用。两个循环在盒图里各自一格，不再像传统流程图那样只画出一个。
【例 5-4】代码
#include <stdio.h>
int main(void)
{
    int i, count=0;
    double score[10], sum=0, aver;
    // 输入成绩，同时累加求和；10 个成绩全部留在数组里
    for(i=0; i<10; i++)
        { scanf("%lf", &score[i]); sum += score[i]; }
    // 求平均，再用同一批成绩逐个比较
    aver = sum/10;
    for(i=0; i<10; i++)
        if(score[i] > aver) count++;
    printf("该组平均分为:%.2f\n", aver);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}

  • ② 从 i = 1 扫到 i = 9，遇到更大／更小值就更新；
  • ③ 循环结束一次输出两个结果。

【例 5-5】代码
#include <stdio.h>
int main(void)
{
    int a[10], i, max, min;
    // 输入 10 个整数
    printf("Enter 10 integers:\n");
    for(i=0; i<10; i++)
        { printf("%d:", i+1); scanf("%d", &a[i]); }
    // 以数组里已有的元素作为初值，再逐个比较
    max = min = a[0];
    for(i=1; i<10; i++)
        { if(max < a[i]) max = a[i]; if(min > a[i]) min = a[i]; }
    printf("Maximum value is %d\n", max);
    printf("Minimum value is %d\n", min);
    return 0;
}

算法要点
  • ① a[0] 始终保存「当前扫描到的最小值」；
  • ② 一旦 a[i] 更小就立刻交换，让最小值浮到首位；
  • ③ 被换到后面的元素不会再与 a[0] 比较。
本例数据共交换 3 次（i = 1、2、4）；方法 2「先找到再交换」只交换 1 次。
方法 1 代码（边找边换）
#include <stdio.h>
int main(void)
{
    int i, t, a[10];
    for(i=0; i<10; i++)
        scanf("%d", &a[i]);
    for(i=1; i<10; i++)
        if(a[i] < a[0]){ t=a[0]; a[0]=a[i]; a[i]=t; }  // 更小则交换
    printf("处理后：\n");
    for(i=0; i<10; i++)
        printf("%4d", a[i]);
    return 0;
}

方法 2先记录最小值的位置，最后只需将最小值与 a[0] 交换一次。
① 两个变量min 存最小值（初值为首元素）；t 存最小值所在的下标（初值 0，与 min 对应）。

算法要点

  • ③ 循环结束后只交换一次，效率高于方法 1。

#include <stdio.h>
int main(void)
{

    for(i=0; i<10; i++)
        scanf("%d", &a[i]);
    min = a[0];
    for(i=1; i<10; i++)
        if(a[i] < min){ min=a[i]; t=i; }
    if(t != 0){ k=a[t]; a[t]=a[0]; a[0]=k; }    // 只交换一次
    for(i=0; i<10; i++)
        printf("%4d", a[i]);
    return 0;
}

【例 5-8】用函数解决例 5-1
题目把例 5-4 中「统计高于平均分人数」交给函数完成：主函数负责输入、累加、输出，人数由被调函数返回。
#include <stdio.h>
int main(void)
{
    int i, count=0;
    double score[10], sum=0;
    // 输入成绩并累加；数组名 score 作为参数传给 countNum
    for(i=0; i<10; i++)
        { scanf("%lf", &score[i]); sum += score[i]; }
    count = countNum(score, 10, sum/10);
    printf("该组平均分为:%.2f\n", sum/10);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
【例 5-8】被调函数 countNum
int countNum(double a[], int n, double aver)
{
    int i=0, cnt=0;
    // 数组名作参数：a[] 与主函数里的 score 是同一段内存
    for(; i<n; i++)
        if(a[i] > aver) cnt++;
    return cnt;
}
数组名作参数把 score 传给 a[]，函数就能访问这 10 个成绩；n 传入元素个数。
