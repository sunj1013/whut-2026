例7-1　验证哥德巴赫猜想
题目数学领域著名的"哥德巴赫猜想"的大致意思是：任何一个大于 2 的偶数总能表示为两个素数之和。

比如：\(24=5+19\)，其中 5 和 19 都是素数。本实验的任务是设计一个程序，验证 20 亿以内的偶数都可以分解成两个素数之和。

①输入格式

输入在一行中给出一个 (2, 2 000 000 000] 范围内的偶数 N。

②输出格式

在一行中按 "N = p + q" 输出 N 的素数分解，其中 \(p\le q\) 均为素数。

核心这样的分解不唯一（例如 24 还可以分解为 7+17），要求必须输出所有解中 p 最小的解——也就是找到第一组就停。
验证哥德巴赫猜想的算法流程
判断 p 是否为素数
判断 q 是否为素数
同一段逻辑判断 p：从 \(i=2\) 一直试除到 \(\sqrt{p}\)。换到 q，整套流程再走一遍——只是把 p 换成 q。
main 函数里写两遍判断素数的语句
int main(){
    int p,q,N,i,j;      // … 输入整数 N
    for(p=2;p<=N/2;p++){              // 寻找第 1 个素数
        for(i=2;i<=sqrt(p);i++)
            if(p%i==0) break;
        if(i>sqrt(p)){ q=N-p;       // 再找第 2 个素数
            for(j=2;j<=sqrt(q);j++)
                if(q%j==0) break;
            if(j>sqrt(q)) break;      // 只需第 1 组
    } }
    printf("%d = %d + %d\n",N,p,q);
}
用 isprime 改写：把判断抽成函数
int main(){
    int p,q,N;
    scanf("%d",&N);
    for(p=2;p<=N/2;p++){
        if(isprime(p)){
            q=N-p;
            if(isprime(q)) break;
    } }
    printf("%d = %d + %d\n",N,p,q);
}
两次素数判断交给 isprime，主函数只写两次调用

例7-2　换道题：重复照样出现

要算 \(C(5,2)\) 和 \(C(10,3)\)，公式：\(C(n,k)=\frac{n!}{k!(n-k)!}\)

double a=1,b=1,c=1,i;
for(i=1;i<=5;i++)  a*=i;       // 求 5!
for(i=1;i<=2;i++)  b*=i;       // 求 2!
for(i=1;i<=5-2;i++) c*=i;   // 求 (n-m)!
printf("%f",a/(b*c));
for(i=1;i<=10;i++) a*=i;      // 求 10!
for(i=1;i<=3;i++)  b*=i;       // 求 3!
for(i=1;i<=10-3;i++) c*=i; // 求 (10-3)!
printf("%f",a/(b*c));

①代码冗余

核心逻辑重复书写。

②维护困难

改一个数据，要动三处。

③逻辑混乱

计算全混在 main 里。

comb：main 只剩两行，fact 用了六次
fact：求 n!
double fact(int n){
    int i=1;
    double p=1;
    for(;i<=n;i++)
        p *= i;
    return p;
}
comb：调用 fact 三次
double comb(int n,int m){
    double a,b,c;
    a= fact(n);      // n!
    b= fact(m);      // m!
    c= fact(n-m);    // (n-m)!
    return a/(b*c);
}
主函数：只剩两行调用
printf("%.1f\n",comb(5,2));
printf("%.1f\n",comb(10,3));
输出
10.0　　120.0
算一算fact 只写 7 行，两个组合数被调用 6 次。
7.1　先看清一个函数长什么样——函数定义
函数定义的一般形式
函数类型  函数名（形参类型说明表）{
    说明部分
    语句部分
}
要点定义的目的就是完成某项功能；形参类型说明表说明参数的个数和类型。
对照：我们早已在写 main
int main() {
    int i;
    for(i=1;i<=5;i++)
        printf("\n%5d",i);
    return 0;
}
注意main 也是一个函数，同样遵循这个形式。
  • 类型标识符说明函数返回值的数据类型；缺省为 int；无返回值则定义为 void
  • 函数名由用户自己命名，必须是合法的标识符
  • 形参表说明函数参数的个数和类型；无参时括号内为空
正确与错误的有参函数
正确的有参函数
int max(int x,int y){
    int z;
    z=x>y?x:y;
    return(z);
}
错误的有参函数
int max (int x, y) {  // ✗ 缺 int
    int z;
    z=x>y?x:y;
    return(z);
}
易错形参必须一个一个地写明类型：int x, y 里的 y 没有被声明为 int，编译不通过。写成 int x, int y 才对。
提示函数头末尾没有分号；分号是函数声明（原型）的标志。

int main(){

反例 · 编译不通过函数定义不能写在任何函数的内部——main 里不行，别的函数里也不行。它只能写在最外层，和所有函数并列。
int main(){

        for(i=1;i<=n;i++) p*=x;
        return p;
    }

  • main 的地位程序从 main 开始执行，它是唯一的入口

7.2　函数要不要把结果带回去——返回值

函数名前面那一格叫类型标识符：它既说了这个函数带不带结果回去，也说了带回来的是什么类型。

带结果回去：int max
int max(int x,int y){
    int z;
    z=x>y?x:y;
    return(z);
}
调用处c=max(a,b); 把结果接住。
不带结果：void printstar
void printstar(){
    printf("***************\n");
}
调用处例7-3、例7-4 就是这种：printstar(); 只管调用，不用接值。
注意函数体里没有 return 语句，就应当定义成 void；void 函数里也可以写 return;（提前结束），但不能写 return 值;。
return 语句：交回结果，同时交回控制权
返回语句的两种形式
return 表达式；
return (表达式);
功能使程序控制从被调用函数返回到调用函数中，同时把返回值带给调用函数。
注意返回值的类型与函数定义类型须一致。
示例：int fac(int n)
int fac(int n){
    int i,f=1;
    for(i=1;i<=n;i++)
        f*=i;
    return (f);
}
int main(){
    …
    return 0;
}
有多个 return，只走遇见的第一个
说明一函数中可以有多个 return 语句，但只执行遇见的第一个——碰到 return，函数立即结束、把控制权交回调用函数。
isprime：三处 return
int isprime(int x){
    int i=2;
    if(x<2) return 0;
    for(;i<=sqrt(x);i++)
        if(x%i==0) return 0;
    return 1;
}
三个数，三次走不同出口
调用先碰到哪一句返回
isprime(1)第 ① 句 x<2 成立0
isprime(4)第 ② 句 4%2==00
isprime(17)2、3、4 都不整除，走到底1

三个数走了三个不同的出口，可每一次只执行一个 return——碰到就结束，后面的再也轮不到。

所以别指望「最后那句 return 1; 兜底」：想让它执行，前面几处判断必须一次都不成立。

两种边角情况：没写 return、类型不一致
① 没有 return 也会返回
void printstar(){
    printf("***************\n");
}
走到末尾自然回执行到函数末尾的 } 就回到调用处。void 函数也可以写 return;（后面只有分号），表示提前结束、不带值。
② 类型不一致，按函数类型转
int f(){
    return 3.8;   // 函数类型是 int
}
带回去的是 3，不是 3.8
悄悄发生，不报错所以更危险——养成"返回值和函数类型写一致"的习惯。
顺便说清 return 0;main 里的 return 0; 是结束整个程序，把 0 交还给操作系统，表示"正常结束"。
返回值怎么用：当条件、赋给变量、当实参
一句话调用处拿到的是一个“值”：isprime 带回 0 或 1，所以它能直接放进 if，也能赋给变量。
① 直接当条件
if(isprime(17))
    printf("17 是素数\n");
② 先赋给变量，再判断
t = isprime(17);
if(t) printf("是素数\n");
③ 当实参、参与运算
s += isprime(i);      // 是素数就加 1
printf("%d",isprime(n));
④ 功能是一回事，返回什么是另一回事
int n, sum=0;
while( scanf("%d",&n) == 1 )   // 读到了几个？
    sum += n;
看 scanf它的功能是从键盘读一个数，返回值却是「成功读到了几个」——两件事。功能写在函数名上，返回什么得看它的说明；所以第 ④ 段能拿「读到 1 个」当条件。
7.3　函数的参数：形参 vs 实参
例7-5　求两个数的最大值
float max(float x,float y);   // 形参
int main(){
    float a,b,c;
    scanf("%f%f",&a,&b);
    c=max(a,b);               // 实参
    printf("max is %f\n",c);
}
float max(float x,float y){   // 形参
    float z=x>y?x:y;
    return z;
}

①形式参数（形参）

在定义函数时，函数名后面括号里的变量名。

②实际参数（实参）

在调用函数时，函数名后面括号里的表达式。

本例输入 3.5 8.3，输出 max is 8.300000。
对不上就出事少给参数直接报错；数目对了、顺序传反，编译器不吭声，结果默默算错。
形参什么时候生，什么时候灭
形参
  • 分配时机调用时才分配内存
  • 释放时机调用一结束就释放
  • 作用域只在函数内部有效
实参
  • 可以是常量、变量、表达式、函数调用
  • 前提调用时必须已有确定的值
以 isprime 为例
int isprime(int x){
    int i=2;
    if(x<2) return 0;
    for(i=2;i<=sqrt(x);i++)
        if(x%i==0)  return 0;
    return 1;
}
if(isprime(p)){ q=N-p;
    if(isprime(q)) break; }
一句话形参是调用那一刻才生出来的副本，函数一返回就没了——下一页看它是怎么交过来的。
参数传递：一份副本，单向流入

调用时，主调函数把实参的值复制一份交给形参——这叫按值调用（Call by Value），系统为形参另开独立的存储单元。

就拿这 8 行代码走一遍
void f(int x){     // 形参 x
    x = 20;
}
int main(){
    int a = 10;
    f(a);             // 实参 a
    printf("%d",a);  // 输出几？
}
表里三行，就是这三步
时刻实参 a（main）形参 x（函数）
调用前a = 10还没有这个单元
调用中a = 10x = 10，被改成 20
返回后a = 10单元已释放
核心特征单向流动　只能实参 → 形参，改形参不动实参。所以上面打印出来是 10。
推下去想靠传参数改主调函数的变量，做不到——下一节 swap 就栽在这儿。
swap 为什么换不过来
void swap(int x,int y) {
    int temp = x;
    x = y;
    y = temp;
    printf("Inside swap: x=%d, y=%d\n",x,y);
}
int main() {
    int a=10, b=20;
    printf("Before swap: a=%d, b=%d\n",a,b);
    swap(a, b);   // 传的是值
    printf("After swap: a=%d, b=%d\n",a,b);
    return 0;
}
运行输出
Before swap: a=10, b=20 Inside swap: x=20, y=10 After swap: a=10, b=20
  • ① 调用时a、b 复制给 x、y
  • ② 执行中只换 x、y，a、b 没动
  • ③ 结束后x、y 释放，a、b 原样
一句话换的只是副本，main 里的原件纹丝不动。
7.4　函数声明：先打个招呼，编译器才认
从上往下扫编译器遇到函数调用时，必须在这之前已经见过它的定义或声明。
int main() {
    int res = add(3,5);  // 编译器还没见过 add
    printf("%d", res);
}
int add(int x,int y) { return x + y; }
编译错误'add' was not declared in this scope
让编译器"见过"它的三条路
  • 库函数用 #include 把信息包含进来，如 <stdio.h>、<math.h>
  • 自定义函数把定义写在调用之前；或与主调函数放在同一文件
  • 最常用在文件开头写一行函数原型，一次管住全篇
函数声明：写在哪儿、怎么写
什么时候必须声明除 int、char 型函数外，若主调函数写在被调函数前面，就必须在调用前声明一下。
函数原型的两种写法
类型说明符 函数名(类型 形参, 类型 形参…);   // 带名字
类型说明符 函数名(类型, 类型…);            // 只给类型

①带形参名

int max(int a, int b); 形参名可写可省，末尾分号不能省。

②只写类型

int max(int, int); 只通报参数个数与类型。

这几种可以省定义写在调用之前 · int/char 型函数 · 已在文件开头统一声明 · 库函数只需 #include。统一写在开头最不容易出错。
定义是"做出来"，声明是"打个招呼"
函数定义形式：实现功能
函数类型  函数名（形参类型说明表）{
    说明部分
    语句部分
}
作用给出函数的完整实现，编译时要生成代码。
函数声明形式：向编译系统通报
类型说明符 被调函数名(类型 形参，类型 形参…);
类型说明符 被调函数名(类型，类型…);
作用告诉编译器"有这么个函数、返回什么、要几个什么类型的参数"，不生成代码。
对照定义是"把功能做出来"，声明是"提前打个招呼"；一个函数只能定义一次，声明可以出现多次。
例7-6　求 m~n 之间的素数和
输入两个正整数 m、n，输出它们之间（含 m、n）的全部素数，并求出这些素数的和。

①输　入

一行两个正整数 m、n，用空格隔开。

保证 2 ≤ m ≤ n ≤ 1000，不必查错。

②输　出

先打印 Sum of ( ，再从小到大打印每个素数（每个后面跟一个空格），最后打印 ) = 和。

样例一
输入：10 30 输出：Sum of ( 11 13 17 19 23 29 ) = 112
样例二　区间里一个素数也没有
输入：8 10 输出：Sum of ( ) = 0
看括号两个括号里头都有一个空格，照抄样例。
看样例二8、9、10 都不是素数，括号空着，和就是 0。
全部写在一个函数里
int main(){
  int m, n, i, k, s = 0, flag;
  scanf("%d %d", &m, &n);
  printf("Sum of ( ");
  for( i = m; i <= n; i++ ){      // ① 三件事都在这一层
    flag = 1;                     // ② 判断：缩进两层
    for( k = 2; k <= sqrt(i); k++ )
      if( i % k == 0 ){ flag = 0; break; }
    if( flag ){
      printf("%d ", i);
      s += i;
    }
  }
  printf(") = %d\n", s);
}

int prime( int p ){      // 给我一个整数
    int i = 2;

    return 1;
}                          // 我回答：是，还是不是

②返回为什么是 int

问题1 梅森数
问题1形如 \(2^{n}-1\) 的素数称为梅森数（Mersenne Number）。例如 \(2^{2}-1=3\)、\(2^{3}-1=7\) 都是梅森数。1722 年，双目失明的瑞士数学大师欧拉证明了 \(2^{31}-1=2147483647\) 是一个素数。
任务与格式

编写程序，对任一正整数 n（n<20），输出所有不超过 \(2^{n}-1\) 的梅森数。

输入：在一行中给出正整数 n（n<20）。

输出：从小到大输出所有不超过 \(2^{n}-1\) 的梅森数，每行一个；没有就输出 "None"。

输入 / 输出样例
6 3 7 31
思路用两个变量：p 记这一轮的 \(2^{i}\)，m 记 \(2^{i}-1\)。p 的初值给 2（就是 \(2^{1}\)）；i 从 2 数到 n，每轮先 p=p*2 把 p 变成 \(2^{i}\)，再 m=p-1，判断 m 是不是素数。
不用从头算上一轮 p 已经是 \(2^{i-1}\)，这轮 p=p*2 就到 \(2^{i}\)（i=2→4、3→8、4→16、5→32）——不必每轮从头重算。n=19 时重算要乘 190 次，递推只乘 18 次。

看结构三层套在一起：外层 for 循环，循环体里一个 if，循环结束后再判断一次 count==0。

isprime 函数
int isprime(int x){
    int i=2;
    if(x<2) return 0;
    for(i=2;i<=sqrt(x);i++)
        if(x%i==0)return 0;
    return 1;
}
主函数
int main(){
    int n,i=2,count=0,p=2,m;
    scanf("%d",&m);  // … 读入 n
    for(;i<=n;i++){
        p*=2; m=p-1;   // 2^i - 1
        if(isprime(m)){
            count++;
            printf("%d\n",m); }
    }
    if(count==0) printf("None");
}
问题2 约分最简式
问题2分数可以表示为分子/分母的形式。编写程序，要求用户输入一个分数，然后将其约分为最简分式。最简分式是指分子和分母不具有可以约分的成分了，如 6/12 可以约分为 1/2。
输入与输出格式

输入：一行中给出一个分数，分子分母以斜杠 / 分隔，如 12/34 表示 34 分之 12；分子分母都是正整数。

输出：一行中输出最简分式，格式与输入相同，如 5/6 表示 6 分之 5。

边界分子大于分母时不必写成带分数，11/8 仍是 11/8；分子分母相等时仍写成 1/1。
输入 / 输出样例
66/120 11/20
思路分子、分母同时除以它们的最大公约数即可——把"求最大公约数"单独写成一个函数。
约分最简式：先写主函数
主函数：读入分子分母 → 求最大公约数 → 各自除一下
int gcd(int x, int y);        // 函数声明：下面要用它

int main(){
    int fenzi, fenmu, gongyue;   // 分子、分母、最大公约数
    scanf("%d/%d", &fenzi, &fenmu);
    gongyue = gcd(fenzi, fenmu);  // 函数调用
    printf("%d/%d", fenzi/gongyue, fenmu/gongyue);
    return 0;
}

①函数声明

gcd 定义在后面，调用前先写原型。

②函数调用

gongyue = gcd(fenzi, fenmu) 拿到最大公约数。

③约分输出

分子分母同除以 gongyue，得到最简分式。

再写 gcd：辗转相除法，除到余数为 0
main 里那句 gcd(fenzi, fenmu)，要的就是它
int gcd(int m, int n){
    int r;
    do{
        r = m % n;
        m = n;
        n = r;
    }while(r != 0);
    return m;
}

①取余

r = m % n

②轮换

m = n，n = r

③终止

r 为 0 时，m 就是最大公约数
