第 7 章　函数
主题 函数中的参数传递（2）——数组名

核心问题

怎样把一整个数组传给函数，让函数直接处理数组中的每一个元素？

本章路线

数组名作实参 → 传首地址 → 形参与实参共用同一段存储单元。

【例 5-4】利用函数解决例 5-1 中的问题
数据分析 设置一个包含 10 个 double 类型变量的数组 score，用来存储所有学员的成绩。 
double score[10];
处理流程
① 定义数组
② 获取（输入）学生成绩，并累加到 sum
③ 计算平均成绩
④ 计算成绩高于平均分人数
⑤ 输出结果
【例 5-4】主函数（一）：定义数组、输入成绩
#include <stdio.h>
int main(){
    int i, count = 0;
    // 定义含有 10 个元素的数组 score 存储学员成绩
    double score[10], sum = 0, aver;
    // 获取 10 个成绩，同时累加到 sum 中
    for(i=0; i<10; i++){
        // 利用循环变量 i 作为数组下标遍历数组
        // &score[i] 取得数组元素 score[i] 的地址
        scanf("%lf", &score[i]);
        sum += score[i];   // 将输入的成绩 score[i] 存入 sum 中
    }
要点 &score[i] 是第 i 个元素的地址；循环逐个读入并累加，把 10 个成绩都保存在数组里。
【例 5-4】主函数（二）：求平均、统计人数、输出
    // 接上页：由累加和求平均分
    aver = sum/10;
    // 将每个成绩依次与 aver 比较
    for(i=0; i<10; i++)
        if(score[i] > aver) count++;
    printf("该组平均分为:%.2f\n", aver);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
函数化的目标 把"统计高于平均分人数"这一步单独抽成函数 countNum —— 这就是接下来要做的事。
【例 5-4】用 countNum 函数求高于平均分的人数
#include <stdio.h>
int main(){
    int i, count = 0;
    double score[10], sum = 0, aver;
    for(i=0; i<10; i++){
        scanf("%lf", &score[i]);
        sum += score[i];
    }
    // 调用函数 countNum 计算成绩高于平均分的人数
    count = countNum(score, 10, sum/10);
    printf("平均分为:% .2f\n", sum/10);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
countNum 函数：数组名作形参
int countNum(double a[], int n, double aver){
    int i = 0, count = 0;
    for(; i<n; i++){
        if(a[i] > aver) count++;
    }
    return count;
}
形参 double a[] —— 方括号里不写长度，它接收的是实参数组的首地址。
2）数组名作为函数实参
01 用数组名作为实参调用函数，可以把整个数组传递给一个函数。
02 用数组名或数组元素地址作实参，实际上是把数组或数组元素的首地址传给被调函数，使形参数组与实参数组指向相同的首地址。
实质 调用时传入的是数组首地址；定义时收到的是同一个地址 —— 两者指向同一段存储单元。
调用时:
countNum(score, 10, sum/10);
定义时:
countNum(double a[], int n, double aver)
a. 数组名作实参，形参用数组定义
用数组名作为实参调用函数，形参数组与实参数组具有相同的首地址、占用同一段存储单元。
① 调用时：实参把数组的首地址交给形参，两个名字指向同一段存储单元。
② 执行中：通过形参下标改元素，改的就是实参那一格，实参同步改变。
③ 返回后：形参消失，实参里已经是新值——修改真正生效了。
【例 7-9】用数组名作参数求数组元素的平均值
题目 一个学生 5 门课程的成绩存放在数组里，求平均成绩：成绩由键盘输入，求和与求平均交给一个函数完成，结果保留两位小数。
运行结果
input 5 scores: 89 88 76 90 92 average score is 87.00
思考 调用时要传数组名和元素个数；要得到平均值，aver 应返回 float。aver 的类型与参数该怎么写？
【例 7-9】main 与 aver 两个函数
主函数 main：它怎么调用 aver
int main(){
    float sco[5], avr;
    int i;
    printf("input 5 scores://n");
    for(i=0; i<5; i++)
        scanf("%f", &sco[i]);
    avr = aver(sco, 5);
    printf("average score is %5.2f", avr);
    return 0;
}
被调函数 aver：形参怎么接
float aver(float a[], int n){
    int i;
    float av, s = a[0];
    for(i=1; i<n; i++)
        s = s + a[i];
    av = s/n;
    return av;
}
置空原因 形参 a[] 方括号里不写长度 —— 调用只传首地址、不传数组大小；元素个数由参数 n 单独传入。
【例 7-9】数组名传参：地址是怎么过去的
橙色：实参 sco 与假设地址 蓝框：形参 a、n 紫框：返回值交给 avr
点一下走一步（1 / 9）
结论 数组名作参数，传出去的是首地址 0x62fe30；形参 a 收下它，a[i] 就落到 sco[i] 那一格上。
所以「地址传递」说到底还是传值 —— 传的仍然是一个值，只不过这个值恰好是一个地址。
【例 7-9】拆分为 aver 与 getsco 两个函数
int main(){
    float sco[5], avr;
    getsco(sco, 5);   // 传址：数组名
    avr = aver(sco, 5);
    printf("average score is %5.2f", avr);
    return 0;
}
float aver(float a[], int n){
    int i;
    float avr, s = a[0];
    for(i=1; i<n; i++)
        s = s + a[i];
    avr = s/n;
    return avr;
}
void getsco(float s[], int n){
    int i;
    for(i=0; i<n; i++)
        scanf("%f", &s[i]);
}
【例 7-8_4】用数组名作参数实现两个数的交换
#include <stdio.h>
void swap(int a[]){
    int t;
    t = a[0], a[0] = a[1], a[1] = t;
    printf("Inside swap: a[0]=%d, a[1]=%d\n", a[0], a[1]);
}
int main(){
    int x[2] = {7, 11};
    printf("Before swap: x[0]=%d,x[1]=%d\n", x[0], x[1]);
    swap(x);
    printf("After swap: x[0]=%d,x[1]=%d\n", x[0], x[1]);
}
运行结果
Before swap: x[0]=7,x[1]=11 Inside swap: a[0]=11, a[1]=7 After swap: x[0]=11,x[1]=7
使用数组名作函数参数时应注意的问题
01 形参数组和实参数组的类型必须一致，否则将引起错误。
02 在调用时，只传送首地址而不检查形参数组的长度。
03 当形参数组的长度与实参数组不一致时，虽不至于出现语法错误（编译能通过），但程序执行结果恐与实际不符。
3）数组元素作函数实参
01 数组元素的使用等同于基本型变量，因此数组元素作函数实参时，函数的形参仍然用基本型变量，实参和形参间也是"单向"值传递。
02 当函数调用时，把作为实参的数组元素的值传送给形参变量，从而实现单向的值传递。
实质：实参（数组元素）将值复制给形参变量 —— 与"数组名作实参"传地址完全不同。
【例 7-8_2】用 swap 函数交换两个数（失败）
int swap(int a, int b){
    int t;
    t = a, a = b, b = t;
    return a;
    return b;
}
int main(){
    int x[2] = {7, 11};
    swap(x[0], x[1]);
    printf("%d %d\n", x[0], x[1]);
    return 0;
}
你的程序交换成功了吗？
7 11
说明 没有交换成功：数组元素作实参是单向值传递，形参改变不会传回实参。
【例 5-4】函数化改造：总体分析
数据分析 设置一个包含 10 个 double 类型变量的数组 score，用来存储所有学员的成绩。 
double score[10];
处理流程
① 定义数组
② 获取（输入）学生成绩
③ 计算平均成绩
④ 计算成绩高于平均分人数
⑤ 输出结果
【例 5-4】主函数：调用 getScore 与 countNum
#include <stdio.h>
int main(){
    int count = 0;
    double score[10], aver;
    // 调用函数 getScore 获取成绩并求平均分
    aver = getScore(score, 10);
    // 调用函数 countNum 计算高于平均分的人数
    count = countNum(score, 10, aver);
    printf("平均分为:% .2f\n", aver);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
countNum 函数：统计高于平均分的人数
int countNum(double a[], int n, double aver){
    int i = 0, count = 0;
    for(; i<n; i++){
        if(a[i] > aver) count++;
    }
    return count;
}
返回 count 为高于平均分的人数，由 return 带回主函数。
getScore 函数：输入成绩并求平均分
double getScore(double a[], int n){
    int i;
    double sum = 0;
    for(i=0; i<10; i++){
        scanf("%lf", &a[i]);
        sum += a[i];   // 将输入的成绩 a[i] 存入 sum 中
    }
    return sum/10;
}
要点 形参 double a[] 接收数组首地址；函数内对 a[i] 的操作，就是在操作主函数里的 score 数组。
