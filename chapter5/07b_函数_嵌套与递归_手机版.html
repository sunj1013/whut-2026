第 7 章 　函数（嵌套调用与递归）
主讲：孙骏
本节内容导览

①嵌套调用

函数里再调另一个函数：一层层进去，再回来。

例7-7 就是三层：main → sum → fac。

②递归的两副面孔

自己调自己，或 A 调 B、B 又调回 A。

形式不同，跑法一样：先递推下去，再回溯上来。

③递归成立的条件

有递推公式把问题变小，有终止条件让它停。

缺一个，就是死循环或者根本算不出来。

④三个经典例子

n!、进制转换、a 串数列。

每个都配一张运行轨迹图，跟着箭头走一遍。

贯穿主线递归不难在代码，难在"想不清它怎么跑"。抓住两件事：什么时候停（终止条件）、怎么变小（递推关系）。
本讲学习目标
  • ① 调用链画出 main → sum → fac 的调用与返回箭头
  • ② 递归写法照着 n! 写出一个完整的递归函数
  • ③ 运行轨迹逐行说清 fac(5) 每一步在做什么，递推与回溯分得开
  • ④ 判断对错看出一段递归少了终止条件会出什么问题
  • ⑤ 用得上知道什么情况下该想到递归、什么时候不必
  • ⑥ 动手用递归解决进制转换、数列求和等小问题
先看一次三层调用：main → sum → fac
例7-7求 1!+2!+3!+…+10!，交给三个函数：main 管输入输出，sum 管求和，fac 管阶乘。
读图箭头指向函数头＝调用，指回调用语句＝返回：进去时一层套一层，出来时反过来一层层交回。
7.5　嵌套调用：一个函数里能再调用别的函数
定义一个函数的定义里又调用了别的函数——A 调 B，B 还能调 C，这叫函数的嵌套调用。
sum 里调用 fac
float sum(int n){
    int a; float s=0;
    for(a=1; a<=n; a++)
        s += fac(a);
    return s;      // sum 里调 fac
}
进去main 里写 sum(10)，sum 里又写 fac(a)——一层套一层。
出来fac 算完先回 sum，sum 累加完再回 main：后进先出。
记住函数之间只靠两样东西来往：参数把数据递进去，返回值把结果带回来。
main 只交活：写清声明，剩下一句调用
例7-7　求 1!+2!+3!+…+10!
函数申明与 main
float  sum(int n);
float  fac(int a);
int main ( ){
    float x;
    x=sum(10);
    printf("x=%10.1f",x);
    return 0;
}
sum：循环调用 fac
float sum(int n){
    int a;
    float s=0;
    for (a=1;a<=n;a++)
        s+=fac(a);
    return s;
}
要点sum 里并没有自己算阶乘，它把这件事交给 fac。
一个函数只管一件事：fac 就管求 a!
fac：给个 a，还个 a!
float fac(int a){
    float t=1;
    int n=1;
    while (n<=a){
        t=t*n; n++; }
    return t;
}
运行结果
结果：x=4037913.0
只管一件事fac 不关心谁调它，也不管算出来的阶乘要拿去干什么——给个 a，还个 a!，别的一概不问。
看分工main 只管输入输出，sum 只管累加，fac 只管阶乘——每个函数只干一件事，将来哪块不对就改哪块，不用从头翻。
7.6　递归：一层层往回算
问题老师依次问 5 位学生的年龄，有两种问法——哪一种能算出结果？
问法一　每人直接报

问一次答一次，老师问 5 次，拿到 5 个互不相干的数字。

换成程序：5 次输入，或者一个数组。

问法二　一层层往下问

第 1 位：我比第 2 位大 2 岁
……
第 4 位：我比第 5 位大 2 岁
第 5 位：我今年 18 岁

于是18 → 20 → 22 → 24 → 26：一层层往回算。这种「要算我，先去问下一位」的办法，就叫递归。
关键第 5 位必须直接说出 18 岁，否则前面四句永远算不出结果——这个「不再往下问」的条件，就是递归的终止条件。
例7-8　一直问到第 5 位，再一层层加回来
age：递归函数 + 主函数
#include <stdio.h>
int age(int n){
    int c;
    if(n==5) c=18;      // 问到最后一个
    else c=age(n+1)+2;  // 再往下问一位
    return c;
}
int main(){
    printf("%d",age(1));
    return 0;
}
运行结果：26
把刚才那几句话，逐句翻成代码
生活里这么说代码里就这么写
问第 n 位的年龄age(n)
再去问下一位age(n+1)
我比他大 2 岁+2
第 5 位直接报 18if(n==5) c=18;
为什么要翻左边是人嘴里的话，右边是机器认的话——写递归时先把左边问清楚，右边几乎自己就出来了。
看两行if(n==5) c=18; 是终止条件；c=age(n+1)+2; 是递归关系——问的人往后挪一位，挪到第 5 位就到底。
递归的两个阶段：递推下去，回溯上来
两个阶段

递推（往下）：age(1) → age(2) → … → age(5)，一共 5 次调用。

回溯（往上）：知道 age(5)=18 以后，逐层 +2，算出 26。

代价每往下问一位，就得先把这一位「还没算完」记着；层数越多，记得越多、走得越慢。
自己调自己：直接递归与间接递归
定义C 语言允许函数直接或间接地调用自己，这种调用方式叫递归调用；含递归调用的函数叫递归函数。
一句话递归函数＝在自己的定义里调用自己；直接调自己是直接递归，绕一圈调回来是间接递归。
递归函数必须有终止条件
两件事写得出的递归函数必须有：① 终止条件（初始条件）② 递归关系（每次把问题规模变小）。
反例：把例7-8 里那行 if(n==5) 删掉，就剩下这些
int age(int n){
    int c;
    c=age(n+1)+2;   // ✗ 还在往下问，可没有停的那一行
    return c;
}
后果age 一层层往下问，永远等不到「停」的那一刻——电脑的内存被一层层占满，程序最后崩掉。
口诀先写「什么时候停」，再写「怎么往下走」。
n! 的递归定义：一个底，一条递推
n! =
1(n = 0)
n×(n−1)!(n > 0)
照这个定义，写成程序语句
if(n==0) f=1;         // 底
else f=n*fac(n-1);  // 递推
一路写下去，直到见底
n! = n×(n−1)!
(n−1)! = (n−1)×(n−2)!
……
2! = 2×1!　　1! = 1×0!
0! = 1　←　初始条件
5! = 5×4! = 5×4×3! = 5×4×3×2! = 5×4×3×2×1! = 5×4×3×2×1×0! = 120
注意0!=1 是规定，不是算出来的——没有这个底，递推就停不下来。
五行写出 fac：先停，再变小
fac：递归求 n!
long fac(int n){
    long f;
    if(n==0) f=1;
    else if(n>0) f=n*fac(n-1);
    return f;
}
main：调用一次
#include <stdio.h>
long fac(int n);
int main(){
    int n;
    scanf("%d",&n);
    printf("%d!=%ld\n",n,fac(n));
    return 0;
}

要不要用递归：先看三条
该写递归　三条都占 别硬用递归
① 问题能变小成同类
n! → (n−1)!；第 n 项靠第 n−1 项		 一句循环就能算完
1 加到 100，写递归是多此一举
② 有个能直接答的底
0!=1、第 5 位 18 岁		 层数太深会撑爆
一层压一层，上千层程序就崩
③ 照「下一步」就能想清楚
不用自己把输出的顺序倒过来		 本来两行就写完
if/else 能办的事，别绕成自己调自己
怎么算①②同时成立，才有资格写递归；再加上 ③，才值得写。
一句话递归不是更高级的写法——有些问题用循环写起来特别绕（要自己记住一路上的中间结果），用递归几句话就说清。
习题1　十进制转二进制：余数倒着出
题目将非负整数 n 转换为二进制后输出，建议用递归实现。
递归实现
void dectobin(int n){
    if(n>1) dectobin(n/2);  // 先处理高位
    printf("%d",n%2);       // 再输出末位
}
n=6 → 110
6 怎么变成 110：一直除 2，记余数
为什么对最先算出的余数，其实是二进制里最低的那一位，所以要最后输出——递归的回溯顺序，正好把它倒过来。不用递归，就得开个数组把余数存起来，再倒着打印。
习题2　特殊 a 串数列和：第 n 项靠第 n−1 项
题目求 a + aa + aaa + … （共 n 项）的和，其中 a 是一位数字。
fn：求第 n 项
int fn(int a,int n){
    if(n==1) return a;
    else return fn(a,n-1)*10+a;
}
fn(2,3) 一路展开
fn(2,3) = fn(2,2)×10+2
　　　　= (fn(2,1)×10+2)×10+2
　　　　= (2×10+2)×10+2 = 222
fn(2,3) = 222 SumA(2,3) = 2+22+222 = 246
SumA：把前 n 项加起来
int SumA(int a,int n){
    int i,s=0;
    for(i=1;i<=n;i++) s+=fn(a,i);
    return s;
}
看递推fn(a,n) = fn(a,n−1)×10 + a：在前一项后面再接一个 a，不用从头拼。
非递归不可：Hanoi 塔
接着说前面讲「能不用就不用」——但有一类问题，用循环真写不出来。Hanoi 塔：三根柱子，64 片盘从下往上摞着，要整摞搬到另一根柱子上。这里只看一眼思路，不展开。

①一次一个

三根柱子之间一次只能移动一个圆盘。

②小压大

任何时候小圆盘上都不能放大圆盘。

③顺序不变

最终仍按大小顺序摞在目标柱上。

递归思路把 n 个盘从 A 搬到 C：先把上面 n−1 个搬到 B，再把最大的搬到 C，最后把 n−1 个从 B 搬到 C。
算一算1 个盘 1 步，n 个盘 \(2^{n}-1\) 步；64 片每秒搬一次，也要几百亿年。
