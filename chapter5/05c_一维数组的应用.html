5.3.1　数组应用 I —— 排序

比较法排序

逐个比较、发现更小就交换。

选择法排序

先找最小位置，再一次交换。

冒泡法排序

相邻两数比较，逆序就交换。

目标 输入若干个数存入数组，按由小到大排序后输出。
▶打开排序算法演示动画（比较 / 冒泡 / 选择 / 插入 / 快排 / 归并 / 堆）
1. 比较法排序
由键盘输入 10 个数，按由小到大排序输出。
  1. 将 10 个数存入数组 a。
  2. 将 a[0] 与 a[1]~a[N-1] 依次比较，哪个元素比 a[0] 小就与它交换，最小的数送到 a[0]。
  3. 再将 a[1] 与 a[2]~a[N-1] 依次比较，把最小的数送到 a[1]。
  4. 重复以上步骤。
次数 n 个数总比较次数：\((n-1)+(n-2)+\cdot\cdot\cdot+3+2+1=\frac{n(n-1)}{2}\)
比较法排序：j 逐格扫描与交换
初始数据：5、13、3、9、2 —— i 最小值应放置位置，j 待比较数据位置
算法流程图
规律 第 i 趟把最小数送到 a[i]；j 从 i+1 逐格扫到 N-1，每遇更小就交换，所以一趟可能改变多处位置。
比较法排序：完整动态演示（a[i] 与后面逐格比，遇小就换）
【例】比较法排序：主函数
#include <stdio.h>
int main(){
    int i, j, a[10], k;
    getNumbers(a, 10);
    sortNumbers_Comparation(a, 10);
    for(i=0; i<10; i++)
        printf("%4d", a[i]);
    return 0;
}
流程 定义数组 → 获取 10 个数据 → 数据排序 → 输出排序后的数组元素。
比较法排序：sortNumbers_Comparation
void sortNumbers_Comparation(int a[], int N){
    int i, j, k;
    for(i=0; i<N-1; i++){ // i：最小值应放置的位置
        for(j=i+1; j<N; j++) // j：待与最小值比较的位置
            if(a[i] > a[j])
                k=a[i], a[i]=a[j], a[j]=k;
    }
}
要点 只要 a[i] > a[j] 就立即交换，使 a[i] 始终保持为当前最小值。
getNumbers：随机生成数列
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
void getNumbers(int a[], int N){
    int i;
    srand(time(0));
    for(i=0; i<N; i++){
        a[i] = rand()%101;
        printf("%4d", a[i]);
    }
}
说明 rand()%101 生成 0~100 的随机数；srand(time(0)) 设置随机种子。
随机数函数 rand() 与 srand()
RAND_SEED = (RAND_SEED*123 + 59) % 32767;
  1. rand() 产生 [0~32767) 区间的 1 个整数。
  2. srand(time(0)) 以当前累计秒为参数产生随机序列起始值。
  3. 产生 [0~1) 随机实数：rand()/32767.0。
  4. 产生 [a~b) 随机实数：rand()*(b-a)/32767.0+a。
  5. 产生 [a~b] 随机整数：rand()%(b-a+1)+a。
  6. 32767 是 rand() 的上限值。
2. 选择法排序
由键盘输入 N 个数，按由小到大排序输出。
  1. 将 N 个数存入数组 a。
  2. 先找出 a[0]~a[N-1] 中最小的数（位置 t），与 a[0] 交换。
  3. 再将 a[1]~a[N-1] 中最小的数（位置 t）与 a[1] 交换。
  4. 重复以上步骤。
次数 n 个数总比较次数：\((n-1)+(n-2)+\cdot\cdot\cdot+3+2+1=\frac{n(n-1)}{2}\)
选择法排序：i、j、t 怎么走
初始数据 5、2、13、3、9　　i：最小值应放的位置　j：正在比较的位置　t：目前最小值的下标
规律 t 从 i 起步，j 向右扫；更小就把 t 跳到 j，扫到头才交换——每趟只换一次。
选择法排序：完整动态演示（min 位置与每趟一次交换）

两种方法运行情况比较
两种比较方法（比较法排序与选择法排序）运行情况比较
比较法排序 每一趟中，只要发现更小的元素就立即交换，中间数据变化较多。
选择法排序 每一趟先找到最小元素的位置 t，最后只交换一次，中间数据变化较少。
结论 最终结果相同，但中间数据不同。
3. 冒泡法排序
由键盘输入 N 个数，按由小到大排序输出。
  1. 将 N 个数存入数组 a。
  2. 把 a[0] 与 a[1]、a[1] 与 a[2]……相邻两数比较，逆序则交换，最大数移到 a[N-1]。
  3. 再把前 N-1 个数同样比较，最大数移到 a[N-2]。
  4. 重复以上步骤。
次数 n 个数总比较次数：\((n-1)+(n-2)+\cdot\cdot\cdot+3+2+1=\frac{n(n-1)}{2}\)
冒泡法排序：每趟的最大数冒到右边
趟次第1位第2位第3位第4位第5位
初始3849657613
第 1 趟3849651376
第 2 趟3849136576
第 3 趟3813496576
第 4 趟1338496576
特征 相邻比较、逆序交换；大的数像气泡一样逐趟"冒"到序列右端。
冒泡法排序：完整动态演示（相邻比较，大数逐趟右移）
冒泡法排序：sortNumbers_Bubble
void sortNumbers_Bubble(int a[], int N){
    int i, j, k;
    for(i=1; i<N; i++){
        for(j=0; j<N-i; j++)
            if(a[j] > a[j+1])  // 相邻两数逆序（前 > 后）→ 交换
                k=a[j], a[j]=a[j+1], a[j+1]=k;
    }
}
循环边界 外层 i 从 1 到 N-1；内层 j 从 0 到 N-i-1，避免越界访问 a[j+1]。

  2. 调整 a、c，使 \(a\le c\)。此时 a 最小。

5.3.2　数组应用 II —— 插入
题目 向一个有序数组中插入一个数字，插入后不改变原有顺序。
插入前1234678910（空位）
插入 512345678910
关键 先找到插入点，再把插入点之后的元素向后移位，腾出空位存放 x。
插入 · 方法 1：先找插入点，再移位
  1. 　找到插入点。
  2. 　移位：从前向后循环，从第 1 个元素开始依次与 x 比较；当 x < a[i] 时，将 a[i]~a[8] 依次向后移动。
  3. 　向 a[i] 中插入（存放） x 。
步骤a[4]a[5]a[6]a[7]a[8]a[9]
移位前678910　
移位后5678910
插入 · 方法 1：动画演示（先找插入点，再移位）
插入 · 方法 1 代码：先找插入点
void insertNumber(int a[], int N, int x){
    int i, j;   // i：插入点位置；j：待移动数据位置
    for(i=0; i<N-1; i++)  // 寻找插入位置
        if(x < a[i])
            break;   // 找到插入点后退出循环
    for(j=N-2; j>=i; j--)  // 从后向前移位
        a[j+1] = a[j];
    a[i] = x;   // 插入数据 x
}
两段循环 第一个 for 找插入点 i；第二个 for 从后向前把 a[i] 及之后的元素整体后移一位。
插入 · 方法 2：找插入点同时移位
从后向前循环，直接从最后 1 个元素开始寻找插入点。
  1. 将 a[i] 与 x 比较，若 x < a[i]，说明 x 应插在 a[i] 前面，a[i] 后移。
  2. 下标 i-- 继续比较，直到找到插入点退出循环。
  3. 此时 a[i] < x，把 x 赋值给 a[i+1]。
特点 查找与移位合二为一，一趟循环完成。
插入 · 方法 2：动画演示（边找边移）
插入 · 方法 2 代码
void insertNumber(int a[], int N, int x){
    int i;
    for(i=N-2; i>=0; i--){
        if( x < a[i] )
            a[i+1] = a[i];   // 比 x 大则后移
        else
            break;   // 找到插入点，退出
    }
    a[i+1] = x;   // 插入数据
}
对比 方法 1 用两个 for（先找后移）；方法 2 用一个 for 边找边移，但要注意最后 a[i+1]=x。
插入 · 主函数

5.3.3　数组应用 III —— 删除
题目 不改变顺序，删除数组中指定的数字。
删除前12345578910
删除 5123478910　　
关键 找到等于 x 的元素后，把其后的元素依次前移覆盖它，数组长度减 1。
▶移位动画参考：插入演示（新窗口 · 删除是插入的逆过程：一个前移、一个后移）
删除 · 基础版
void deletenumber(int a[], int N, int x){
    int i, j;
    for(i=0; i<N; i++)
        if(x == a[i])
            for(j=i; j<N-1; j++)
                a[j] = a[j+1];
}
问题 若数组中有多个 x，这个版本只能正确处理部分情况——前移后下标 i 继续递增，会漏掉紧邻的下一个 x。
删除：动画演示（正确做法与两种错误示范）
删除 · 加 i-- 处理连续删除（死循环）
void deleteNumber(int a[], int N, int x){
    int i, j, del=0;
    for(i=0; i<N; i++){   // 删除后容量减小
        if(x == a[i]){
            for(j=i; j<N-1; j++)
                a[j] = a[j+1];
            i--;   // 还原到删除位置，方便处理连续删除
        }
    }
}
易错 删除前：1　2　3　4　5　5　7　8　9　5 —— 死循环：i 回退后没减少有效长度，条件 i<N 永远成立。
删除 · 用 del 记录删除个数
void deleteNumber(int a[], int N, int x){
    int i, j, del=0;
    for(i=0; i<N-del; i++){
        if(x == a[i]){
            for(j=i; j<N-1-del; j++)
                a[j] = a[j+1];
            i--;
            del++;   // 计算删除数据个数
        }
    }
}
删除前：1 2 3 4 5 5 7 8 9 10
删除后：1 2 3 4 7 8 9 10
删除 · 用 while 处理连续相同值
void deleteNumber(int a[], int N, int x){
    int i, j, del=0;
    for(i=0; i<N-del; i++){
        while(x == a[i]){   // 循环停在 i 处，直到 x 变化
            for(j=i; j<N-1-del; j++)
                a[j] = a[j+1];
            del++;
            if(i == N-del) break;   // 避免末尾为待删数导致死循环
        }
    }
}
删除前：1 2 3 4 5 5 7 8 9 5　→　删除后：1 2 3 4 7 8 9
5.3.4　数组应用 IV —— 二分查找
前提 二分法检索（在序列 x[] 中检索 y 的位置）—— 必须是有序数列（以递增序为例）。
原理
  1. 等分区间。
  2. 比较：若 y 小于中间数，取左半边，否则取右半边。
  3. 再等分，再比较……
二分查找 · 基本算法
区间 对于位置区间 [a, b]：
  1. 将其等分为二，求出 k。
  2. 若 y == x[k]，则 k 就是 y 在数列中的位置。
  3. 若 y < x[k]，取新区间 [a, k-1]（即 b=k-1）。
  4. 若 y > x[k]，取新区间 [k+1, b]（即 a=k+1）。
二分查找 · 查找过程示例
下标0123456789
x[i]345678878890101112520888
示例：查找 y=87 初始 a=0, b=9，中点 k=(0+9)/2=4，x[4]=88 > 87 → 取左半边 b=k-1=3；再算 k=(0+3)/2=1，x[1]=56 < 87 → 取右半边 a=2；继续直到 x[3]=87 找到退出。
边界 当 a > b 时区间为空，说明数列中没有 y —— 找完退出。
二分查找：动画演示（区间怎么缩）
二分查找 · 算法流程
步骤操作
1序列区间：起点 a=0，终点 b=9；当 a ≤ b
2求中点位置 k = (a+b)/2
3若 a[k] == y → break（找到）
4若 a[k] > y → b = k-1
5否则 → a = k+1
6输出结果
二分查找 · 主函数
#include <stdio.h>
int main(){
    int x[10], i, k, y;
    getnumbers(x, 10);
    scanf("%d", &y);
    k = searchNumber(x, 10, y);
    if(k != -1)
        printf("x[%d]=%d\n", k, x[k]);

约定 k == -1 表示没找到，否则为 y 的下标。
二分查找 · searchNumber 函数
int searchNumber(int x[], int N, int y){
    int a=0, b=N-1, pos=-1;
    while(a <= b){   // 二分法查找
        pos = (b+a)/2;
        if(y == x[pos]) break;   // 找到后退出
        if(y < x[pos]) b = pos-1;
        else a = pos+1;
    }
    return pos;
}
注意 循环条件是 a <= b；每轮只保留一半区间，效率远高于顺序查找。
5.3.5　数组应用 V —— 统计
题目要求 系统生成 100 个 1~20 之间的随机数，判断各个数值出现的次数。
输入格式

无输入。

输出格式

统计 · 用数组 st 作计数器
核心 用 st[a[i]]++ 统计：以随机数本身作下标，出现一次就给对应计数器加 1。
st 下标12345…17181920
初值00000…0000
例 a[i]=3 → st[3]++
例 a[i]=18 → st[18]++
统计：动画演示（st[a[i]]++ 桶计数）
统计 · 主函数
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int main(){
  int a[100], st[21]={0}, i;
  srand(time(0));
  for(i=0; i<100; i++){
    a[i] = rand()%20+1;
    st[a[i]]++;
  }
  for(i=0; i<100; i++){
    printf("%3d", a[i]);
    if((i+1)%20==0)
        printf("\n");
  }
  printf("统计结果：\n");
  for(i=1; i<21; i++)
    printf("%3d", st[i]);
  printf("\n");
  return 0;
}
