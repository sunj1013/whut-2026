第 3 章　选择结构：switch 语句
主讲：孙　骏
回顾：多分支 if 的判断全是"等于某个值"
例：由等级查分数段
char grade;
scanf("%c", &grade);

if(grade=='A') printf("85~100\n");
else if(grade=='B') printf("70~84\n");
else if(grade=='C') printf("60~69\n");
else if(grade=='D') printf("<60\n");
else printf("Error\n");
观察 5 个分支里有 4 个都是 grade == '某字符'——判断的是“变量等于哪个具体的值”，这叫等值判断。
问题 区间判断离不开 if（如 s>=60&&s<70）；可“等于某个值”的多分支，这样一长串 else if 又长又容易写错。
C 的办法 C 语言为此专门提供了 switch 语句（开关语句 / 多分支结构），把“逐个比较某个值”写得更短、更像查表。
3.3.2　switch 语句：语法格式
语法格式
switch (表达式)
{
    case 常量表达式1: 语句组1
    case 常量表达式2: 语句组2
        ⋮
    case 常量表达式n: 语句组n
    default: 语句组n+1
}
注意 语句组不是一条语句：可以写多条，不必加 { }，也无须加分号。
switch(表达式) 由它算出“待比较的值”，必须是整型或字符型（char / int / 枚举），不能是 float、double。
case 常量表达式k “入口标号”，值必须是与表达式同类型的常量（如 'A'、1、2+1），各 case 的值互不相同。
default 所有 case 都不匹配时走这里，处理“其他（非法）”情况；可以省略，位置也可前可后。
执行流程：命中哪个 case，就从哪里往下执行
switch 的执行流程
① 算值 先算出 switch(表达式) 的值（整型 / 字符型）。
② 比对 自上而下与各 case 后的常量逐个比较，找到相等的那一个就进去。
③ 顺流而下 进去之后不再做判断，把后面的语句一条条执行下去，直到遇到 break 或 switch 结构结束（图中右侧的竖线）。
④ 都不匹配 全部 case 都不等时，才走 default 分支。
⑤ 与 if 不同 if 每进一个分支都要重新算条件；switch 只在找入口时判断一次，进去以后一路直下——所以又快又像查表。
直接把 if 改成 switch：出了什么问题？
照原样改写（没有 break）
switch(grade){
    case 'A': printf("85~100\n");
    case 'B': printf("70~84\n");
    case 'C': printf("60~69\n");
    case 'D': printf("<60\n");
    default:  printf("Error\n");
}
先请学生口答：输入 B，屏幕上会依次打印出哪几行？想好了再点下面的按钮
点击显示：实际输出与原因
输入 B 的实际输出
70~84 60~69 <60 Error
原因 case 只是入口标号，本身没有“跳出”功能：匹配到 'B' 后往下走，C、D、default 的语句全被执行——这叫穿透（fall through）。
别急 穿透并不全是坏处——下一页会看到，故意省掉 break 正好能让多个 case 共用一段语句。
break 语句（中断语句）
语句形式 break;

功能：中止本结构

中止 switch 结构（或循环结构）的执行，转去执行该结构的下一条语句——也就是跳出 { }，接着往下走。

使用范围：只在这两种结构里

break 只能用在 switch 结构或循环结构之中，不能单独写在普通语句里。

一句话 switch 里 break 的作用是“执行完本分支就收工”：不加它会一路穿透，加了它才真正实现“多选一”。
改进：每个分支末尾加上 break
改进后的 switch 语句
switch(grade){
    case 'A': printf("85~100\n"); break;
    case 'B': printf("70~84\n");  break;
    case 'C': printf("60~69\n");  break;
    case 'D': printf("<60\n");    break;
    default:  printf("Error\n");
}
若 grade = 'C'，则输出
60~69
效果 匹配到 'C' → 打印 60~69 → 遇到 break → 立即跳出 switch，只输出一行。
细节 最后一个分支（通常是 default）后面可以省略 break，因为它后面已没有语句，马上就结束了。
有 break 的执行流程：各分支直接汇入出口
加了 break 之后
① 每条分支都收口 语句组 1、2、n+1 执行完都向右汇入同一条竖线（图中标注 break），直达 switch结束——这就是“多选一”。
② 与左图对比 上一页那张图里，语句组之间是上下相连的（会穿透）；这张图里语句组之间不再相连，只剩右侧出口。
③ 记住 判断只在“找入口”时做一次；进去以后要么 break 出去，要么顺序执行到底。
④ break 只管一层 它只跳出最近的 switch（或循环）。若 switch 写在循环里，break 跳出的是 switch，不会结束循环。
巧用“形式一”：多个 case 共用一组语句
switch 语句形式一（无 break）的作用
switch(grade){
    case 'A':
    case 'B':
    case 'C': printf("60~100 合格\n"); break;
    case 'D': printf("<60 不合格\n");    break;
    default:  printf("Error\n");
}
原理 'A'、'B' 后面故意不写语句、也不写 break，于是“滑落”到 'C'，三个入口共用同一段打印语句。
规矩 共用语句写在最后一个 case 之后，然后再写 break；输入 A / B / C 结果都一样。
提醒 只有确实要共用时才省 break，否则就是上一页那个“穿透”错误。
【例 3-5】输出月份对应的季节
题目要求 输入一个月份，输出对应的季节。

春

3、4、5 月

夏

6、7、8 月

秋

9、10、11 月

冬

12、1、2 月

输入 / 输出格式 输入：一个代表月份的整数。
输出：根据输入值输出当月是什么季节。
请输入月份: 10 10月是秋季。
想一想 12 个“等于几”的判断，用 switch 写比 if 短得多——而且同一季节的 3 个月正好可以共用一个出口。
【例 3-5】参考代码
#include<stdio.h>
int main()
{
    int month;
    printf("请输入月份:");
    scanf("%d", &month);
    printf("%d月是", month);
    switch(month)
    {
        case 12: case 1: case 2: printf("冬季\n"); break;
        case 3:  case 4: case 5: printf("春季\n"); break;
        case 6:  case 7: case 8: printf("夏季\n"); break;
        case 9:  case 10: case 11: printf("秋季\n"); break;
        default: printf("输入错误\n");
    }
    return 0;
}
① 共用入口 同一季节的 3 个月写成一串 case，只在最后一个后面跟语句和 break。
② 每组都收口 每组末尾都要 break，否则会把下一个季节也打印出来（下一页细看）。
③ default 兜底 输入 13、0、-1 等非法月份时，走 default 提示“输入错误”，不让程序“没反应”。
检查：这一组漏了 break 会怎样？
漏写 break 的写法
switch(month)
{
    case 12: case 1: case 2: printf("冬季\n");
    case 3:  case 4: case 5: printf("春季\n"); break;
    case 6:  case 7: case 8: printf("夏季\n"); break;
    case 9:  case 10: case 11: printf("秋季\n"); break;
    default: printf("输入错误\n");
}
错在哪 “冬季”这一组末尾少了 break;
输入 12 的实际输出
12月是冬季 春季 夏季 秋季
走一遍 命中的是 case 2 那一格 → 打印“冬季” → 没有 break，继续往下 → 春季、夏季、秋季依次打印 → 直到“秋季”末尾的 break 才停。
自检 写 switch 时每组末尾先敲一个 break;，再填语句——比写完回头补更不容易漏。
说明：switch 的六条规矩
要点说明
switch(表达式)值须为整型（或字符型）——不能是浮点型。
case 后 E1, E2, … En必须是整型常量或整型常量算术表达式（如 2*3），且各值必须互不相同。
case En只是语句标号，本身无跳出功能；没有 break，程序顺序往下执行。
case 后可执行语句可以有多条，不必加 { }。
多个 case可以共用一组执行语句（形式一，省 break）。
switch 语句可以嵌套：一个 switch 的语句组里还能再写 switch。
最易错两条 ① switch 括号里的值不能是浮点型；② case 后必须是整型常量——case 2,4: 与 case 变量: 都不行。
练一练：哪个 switch 语句是正确的？
题 7 若有定义 float x=1.5; int a=1,b=3,c=2;，则正确的 switch 语句是 ＿＿＿＿。

A

switch(x)
{ case 1.0: printf("*\n");
  case 2.0: printf("**\n");
}

B

switch((int)x)
{ case 1: printf("*\n");
  case 2: printf("**\n");
}

C

switch(a+b)
{ case 1: printf("*\n");
  case 2,4: printf("**\n");
}

D

switch(a+b)
{ case 1: printf("*\n");
  case c: printf("**\n");
}
点击显示解析
答案 B (int)x 把 1.5 强制转成整型 1，switch 得到整型值，case 1 / case 2 也是整型常量 —— 全部合法。
A / C / D 为什么错 A：switch(x) 的 x 是 float；C：case 2,4: 是逗号表达式；D：case c: 的 c 是变量。三条都是“case / 表达式不是整型常量”的错。
解析：编译器替我们排除了三个
核心 switch 括号里的值、case 后面跟的值——都必须是整型（或字符型）的常量。违背这条，编译直接失败。

A　switch(x)　x 是 float

表达式不是整型。编译器报：
error: switch quantity not an integer

B　switch((int)x)　✔

先强制转换再比较，case 1、case 2 是整型常量，完全合法。

C　case 2,4:　逗号表达式

一个 case 只能跟一个常量。编译器报：
error: expected ':' before ',' token

D　case c:　c 是变量

case 后必须是常量。编译器报：
error: case label does not reduce to an integer constant

记住 想“多个值走同一段”，只能像例 3-5 那样写成一串 case 叠起来，不能写 case 2,4:，也不能写 case 变量:。
实机验证：三种写法都被编译器拦下
A 选项：switch(x) 而 x 是 float —— 编译失败
C 选项 case 2,4: error: expected ':' before ',' token D 选项 case c: error: case label does not reduce to an integer constant
结论 三种错误都过不了编译——不需要死记，敲一遍、看一眼报错就记住了。
还要分清两种错 语法错（这三张图）：编译器直接拦下，程序根本跑不起来；逻辑错（上一页漏 break）：编译通过、运行结果却是错的——后者更隐蔽，写完一定要拿几个输入试一遍。
总结：if-else if 与 switch 怎么选
比较项多分支 if – else ifswitch 语句
擅长区间 / 复合条件（s>=60&&s<70）等值判断（grade=='A'、month==1）
条件类型任意表达式，非 0 即真只能是整型 / 字符型表达式
可读性分支多时层层缩进，易乱像查表，一目了然
跳出执行完自动结束，无需 break必须写 break，否则穿透
用 if 判范围、判大小、判组合条件——只能用它。
用 switch 判“等于哪个固定值”：菜单选择、等级分类、月份季节。
考试常考 “下列 switch 语句哪个正确”——先看括号里是不是整型/字符型，再看 case 后是不是常量，两条就能排掉大多数错项。
本节小结

①switch 格式

表达式取整型/字符型，与各 case 常量比对，都不中则走 default。

②case 只是入口

它没有跳出功能；不写 break 会穿透，把后面各组的语句一起执行。

③多 case 共用

故意省 break，让多个入口落到同一段语句——例 3-5 的四季就是这么写的。

④怎么选

范围/复合条件用 if；等值多分支用 switch。
