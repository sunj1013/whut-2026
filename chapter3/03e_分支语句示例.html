例3-6　判断输入的字符是哪种类型
题目

通过键盘输入一个字符，编程判断并输出用户输入的是什么类型的字符。

字符范围应输出
'0' ~ '9'This is a digit.
'A' ~ 'Z'This is a capital letter.
'a' ~ 'z'This is a small letter.
其他Other character.
先想一想 数字、大写、小写字母在 ASCII 表里是三段互不相连的区间。
输入输出样例
输入样例: 6 输出样例: This is a digit.
用什么读 只读一个字符，用 ch=getchar();；scanf("%c",&ch) 也行。
例3-6　流程图：三个菱形依次筛，最后落到 else
不重不漏 四个范围互不重叠，合起来覆盖全部字符——前三个不成立时，剩下的一定是“其他”。
注意顺序 'A'~'Z' 与 'a'~'z' 的 ASCII 码不相连，必须分开判断。
出口 四条分支最后汇合到同一个结束——选择结构只有一个入口、一个出口。
例3-6　写法一：if–else if 逐段判断
#include <stdio.h>
int main(){
    char ch;
    ch = getchar();              /* 只读一个字符 */
    if(ch>='0' && ch<='9')
        printf("This is a digit.");
    else if(ch>='a' && ch<='z')
        printf("This is a small letter.");
    else if(ch>='A' && ch<='Z')
        printf("This is a capital letter.");
    else
        printf("Other character.");
    return 0;
}
关键一 区间判断必须写成 ch>='0' && ch<='9' 这种逻辑与形式，C 语言不允许写数学上的 '0'<=ch<='9'。
关键二 四个分支是互斥的，所以用 else if 串联——一旦命中就不再往下判断，效率高，也不会重复输出。
想一想 每条 printf 都只有一条语句，所以不用加 { }；这也是教材上的写法。
例3-6　写法二：switch 的范围 case
switch(ch){
    case '0' ... '9':
        printf("This is a digit.");          break;
    case 'a' ... 'z':
        printf("This is a small letter.");   break;
    case 'A' ... 'Z':
        printf("This is a capital letter."); break;
    default:
        printf("Other character.");
}
这是扩展语法 case '0' ... '9' 是 GCC 扩展（GNU C 专有），PTA 用 gcc 能过，标准 C 不支持。
标准写法 要一条条列出来共用一组语句：
case '0': case '1': ... case '9': printf("This is a digit."); break;
取舍 字符范围用 if 更自然；switch 适合离散的几个值（如月份 1–12）。
例3-7　输入年、月，输出该月有多少天
题目 输入年份和月份，输出该月共有多少天。
year=2013 month=6 2013年6月有30天
分析 1、3、5、7、8、10、12 月 —— 31 天；
4、6、9、11 月 —— 30 天；
2 月 —— 闰年 29 天，平年 28 天。
闰年的判定

年份能被 4 整除但不能被 100 整除，或者能被 400 整除。

if(year%4==0 && year%100!=0 || year%400==0)
年份是否闰年
2000是（能被 400 整除）
1900否（能被 100 整除）
2013否（不能被 4 整除）
例3-7　代码：多 case 共用 + case 里嵌 if
#include <stdio.h>
int main(){
    int year, month, days;
    printf("year=");  scanf("%d", &year);
    printf("month="); scanf("%d", &month);
    switch(month){
        case 1: case 3: case 5: case 7: case 8: case 10:
        case 12: days=31; break;
        case 4: case 6: case 9: case 11:
                  days=30; break;
        case 2:   if(year%4==0 && year%100!=0 || year%400==0)
                      days=29;
                  else
                      days=28;
    }
    printf("%d年%d月有%d天\n", year, month, days);
    return 0;
}
多 case 共用 12 个 case 只写了两句 days=…：前面的 case 后面什么都不写，自然落到下一行共用语句。
case 2 特殊 天数分两种，所以这一支里嵌一个 if–else；它执行完就到 }，不需要 break。
没有 default 月份只可能是 1–12，已全部覆盖，default 可以省略。
例3-8　计算该日期是这一年的第几天
题目 输入一行日期，格式 yyyy/mm/dd，输出它是该年的第几天。
输入输出说明
2009/03/026131+28+2
2000/03/026231+29+2
差别就在 2000 年是闰年，2 月多一天——2 月的天数必须先判断。
两条路都能走到
思路一 把前面 m-1 个整月的天数加起来，再加当月的日 d——用 switch(m-1) 从大往小穿透累加。
思路二 反过来，从 m 月数到 12 月——用 switch(m)，得到的是距年末还剩几天（新年倒计时）。
核心技巧 两次都故意不写 break，让 case 一路穿透，把“多个分支都执行一遍”变成“累加”。
例3-8　思路一：switch(m-1) 逐月累加
怎么读 从 case m-1 进来后一路往下走：每过一层加一个整月，最后到 case 0 加当月的日 d。
例 m=3 switch(2) → 2 月（29 或 28）→ 1 月（+31）→ +d，共 61 或 62。
为何不写 break 这里要的就是穿透——“经过的每一层都加一次”，正是累加。
初始化 days 必须先置 0，否则加的是随机值。
例3-8　思路二：switch(m) 从 m 月数到 12 月
反过来数 从 case m 进来往下穿透，把 m 月到 12 月的整月天数全加上，最后减去当月的日 d。
它算的是 距年末还有几天（新年倒计时）：m=12、d=31 时结果为 0。
要第几天 用全年天数减：365+闰年-days，或干脆用思路一。
共同骨架 两张图只差入口表达式（m-1 / m）与最后修正（+d / -d）。
例3-8　代码：把图 2 的每一步写成一行
#include <stdio.h>
int main(){
    int y, m, d, days = 0;
    scanf("%d/%d/%d", &y, &m, &d);
    switch(m-1){
        case 11: days += 30;
        case 10: days += 31;
        case  9: days += 30;
        case  8: days += 31;
        case  7: days += 31;
        case  6: days += 30;
        case  5: days += 31;
        case  4: days += 30;
        case  3: days += 31;
        case  2: if(y%4==0 && y%100!=0 || y%400==0) days += 29;
                 else days += 28;
        case  1: days += 31;
        case  0: days += d;
    }
    printf("%d\n", days);
    return 0;
}
为什么倒着写 穿透是从上往下的，所以 case 必须按 11 → 0 递减排列，才能从 m-1 一路加到 0。
m=1 时 switch(0) 直接落到 case 0，days=d —— 结果正确，不用特判。
输入技巧 scanf("%d/%d/%d") 里的 / 会原样匹配输入中的斜杠，省去手工拆分。
例3-9　分段函数：任意输入 x，输出 y
y =
x( x < 2 )
2x − 1( 2 ≤ x < 10 )
3x + 10( x ≥ 10 )
运行样例
x=3.56 3.560000,6.120000
同一个函数，三种写法
  • 方法一三个独立的 if，各判各的
  • 方法二if – else if – else 互斥串联
  • 方法三switch ＋ 构造入口值 z
方法一　三个独立的 if：各判各的
#include <stdio.h>
int main(){
    float x, y;
    printf("x=");
    scanf("%f", &x);
    if(x < 2)
        y = x;
    if(2 <= x && x < 10)
        y = 2*x - 1;
    if(x >= 10)
        y = 3*x + 10;
    printf("%f,%f\n", x, y);
    return 0;
}
能跑通 三段条件互不重叠、合起来覆盖全体实数，所以 y 一定会被赋到值。
但费事 三个 if 各自判断一遍，每次都要算一遍条件；条件一多就容易写漏、写重。
隐患 如果某段区间写成漏的（比如把 x<10 写成 x<=10），y 就成了未赋值的随机数。
方法二　if – else if – else：互斥串联
#include <stdio.h>
int main(){
    float x, y;
    printf("x=");
    scanf("%f", &x);
    if(x < 2)
        y = x;
    else if(x < 10)        /* 此处必有 x>=2 */
        y = 2*x - 1;
    else                     /* 此处必有 x>=10 */
        y = 3*x + 10;
    printf("%f,%f\n", x, y);
    return 0;
}
条件可以变短 else if 已经隐含了前面条件不成立，所以只需写 x<10，不必再写 x>=2。
效率 一旦命中就不再往下判断；最后一支用 else 兜底，绝不会漏。
推荐 区间判断首选这种写法——switch 只能做等值判断，区间它天生不擅长。
方法三　用 switch 走一遍：先看要做什么
图里的四步
① 读入输入 x —— 这一步与用不用 switch 无关。
② 造 z看 x 落在哪个区间，换成整数 z＝1、2、3。
③ 选路switch(z) 只走一个 case，算完 y 就跳出。
④ 输出打印 x 和 y，结束。
看结构 一条主干进去、一条主干出来，中间三选一——这是 switch 与 if 链最大的不同：它不是“依次判断”，而是“跳到一个入口”。至于第 ② 步的 z 怎么算出来，下一页再拆。
方法三　第 ② 步：把“区间”换成“等值”
难点 switch 只能判断等值，而这里判断的是区间。→ 那就先用条件构造一个整数 z，让三个区间各自对应 z = 1、2、3。
关键工具 C 语言里关系表达式的结果是整数：成立为 1，不成立为 0。
于是可以拼 三个条件各乘一个系数，再加起来，一行就把区间换成了等值：
z = 1*(x<2) + 2*(2<=x&&x<10) + 3*(x>=10);
x 的范围(x < 2)(2<=x && x<10)(x >= 10)z
x < 21001
2 ≤ x < 100102
x ≥ 100013
注意 三个条件必须互斥且完整，否则 z 可能算出 0、4 这类没有 case 对应的值。
方法三　代码：照着图一步步写
#include <stdio.h>
int main(){
    float x, y;
    int z;
    printf("x=");
    scanf("%f", &x);
    z = 1*(x<2) + 2*(2<=x&&x<10)
               + 3*(x>=10);
    switch(z){
        case 1: y = x;       break;
        case 2: y = 2*x-1;   break;
        case 3: y = 3*x+10;
    }
    printf("%f,%f\n", x, y);
    return 0;
}
对着图读代码
第 7–8 行就是图里的“造 z”：三个关系式各出 1 或 0，乘上 1/2/3 再相加。
break 不能少case 1、2 算完 y 立刻跳出；漏掉就会顺着往下算，y 被后面的覆盖。
case 3 后面没写 break它是最后一个，后面就是 }，穿不出去——但建议写全，习惯统一。
老实说 这题用 switch 反而绕。它的价值在于：让你看清“等值判断”与“区间判断”的边界——能换，但不必。
7-8　高速公路超速处罚
规定 在高速公路上行驶的机动车，达到或超出本车道限速的 10% 处 200 元罚款；达到或超出 50% 的，吊销驾驶证。
输入 / 输出
输入：114 102 输出：Exceed 12%. Ticket 200

超速百分比 x 精确到整数：(114−102)/102 = 11.76% → 12%。

三种输出
情形输出
正常行驶OK
超速 ≥10% 且 <50%Exceed x%. Ticket 200
超速 ≥50%Exceed x%. License Revoked
两个坑 ① 百分比要四舍五入成整数；② 边界“达到 10%”取等号，比较时不能用浮点数硬碰。
诊断一　为什么算出来是 11% 而不是 12%
单步调试：Watches 窗口里的实际取值
看这几行 c=(a-b)*100/b 得 11；(a-b)*100.0/b 却是 11.76…
同一组输入的两种结果
实际输出 114 102 Exceed 11%. Ticket 200
正确答案 114 102 Exceed 12%. Ticket 200
表达式结果
(a-b)*100/b11　整型相除，小数丢掉
(a-b)*100.0/b11.7647…　实数运算
…/b + 0.512.26…　取整即 12
结论 两个整数相除结果仍是整数——11.76 被截成 11，四舍五入应是 12。
诊断二　在 PTA 上，它就是这 2 分
提交记录：部分正确 8 / 10
只有一处错 测试点 3「超过百分之 10」答案错误——正是 11 与 12 之差。
为什么只错这一处 其它测试点碰巧整除或小数不足 0.5，截断与四舍五入结果相同，所以都过了。
教训 这种“大部分对、个别错”的提交，八成是溢出、截断、边界取等这类问题，要盯着临界样例测。
正确写法：先算对，再分档
#include <stdio.h>
int main(){
    int speed, limit, rate;
    scanf("%d %d", &speed, &limit);
    rate = ((speed-limit)*1.0/limit)*100 + 0.5;
    if(rate < 10)
        printf("OK");
    else if(rate < 50)
        printf("Exceed %d%%. Ticket 200", rate);
    else
        printf("Exceed %d%%. License Revoked", rate);
    return 0;
}
另一种写法 double rate; 不用 +0.5，输出时用 %.0f 自动四舍五入。
① 乘 1.0 (speed-limit)*1.0/limit 强制转成实数运算，不再截断。
② 加 0.5 +0.5 后赋给 int：小数部分自动舍去，等价于四舍五入。
③ 用 rate 分档 比较的是四舍五入后的整数 rate，边界自然落在 10、50 上，不再碰浮点误差。
④ 别写 if(a < b*0.1+b) 这类浮点比较：1.1×102 = 112.2 本身就有误差。
小结　选择结构的解题四步

①看清判断

是等值（一个值对几个常量）还是区间（范围比较）？前者 switch，后者 if。

②列全分支

条件互不重叠、合起来不漏；最后用 else / default 兜底。

③画流程图

把每个分支和汇合点画出来，漏掉的、重叠的一眼就能看出来。

④抠边界

“达到 10%”是 >= 还是 >？整型还是实数？临界样例必须手算一遍。

易错点对策
区间写成连等2<=x<10 在 C 里恒为 1 → 必须写 x>=2 && x<10
该穿透时写了 break累加类（如第几天）要故意不写 break；分档类必须写
整数除法截断乘 1.0 再算，或干脆用 double
case 后写变量 / 浮点case 只能是整型常量；比较浮点请用 if
