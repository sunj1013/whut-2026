控制运算符：条件是如何运算的？
回顾上节课 综合案例中用到了 a+b>c && a+c>b && b+c>a。
这里的 > 和 && 构成了判断条件。它们是怎么运算的？
本节内容模块

①关系运算符

比较大小，结果为 1（真）或 0（假）

②逻辑运算符

连接多个条件，处理“且”、“或”、“非”

③条件运算符

唯一的三目运算符，简化 if…else

④位运算符

直接对二进制位进行操作，高效且底层

核心概念 在 C 语言中，没有专门的“布尔类型”。
关系、逻辑、位运算的结果都被视为逻辑量：非 0 为真，0 为假。
3.2.1　关系运算符
运算符含义优先级
<小于6（较高）
<=小于等于
>大于
>=大于等于
==等于7（较低）
!=不等于
记忆 <、<=、>、>= 四个同级；
==、!= 两个同级，且比前面四个低一级。
结合方向 关系运算符的结合方向为自左向右。
例如：a > b > c，先算 a > b。
关系表达式的值：真 = 1，假 = 0
定义 关系表达式的结果是一个逻辑量：
　成立 → 结果为整数 1　　不成立 → 结果为整数 0
关系表达式真假结果值
3 + 2 > 55 > 5 不成立0
'A' < 'a'65 < 97 成立1
10 == 10成立1
3 != 3不成立0
应用 因为结果就是整数 1 和 0，所以关系表达式可以直接参与算术运算，也可以直接作为 if 的条件。
例如 int n = (a>0) + (b>0); 可以统计 a、b 中有几个为正数（成立得 1，不成立得 0）。
易错点 ①：区分 = 与 ==
运算符功能运算结果
=　赋值为左侧变量赋值，左侧只能是变量结果为所赋的值
==　相等判断判断左右两端的值是否相等结果为 0 或 1
警示 if(a = 7) 是合法表达式，编译器不报错，但逻辑完全错误——这是最常见的“隐形 bug”。 
// 程序 A：赋值
int a = 10;
if(a = 7)
    printf("YES!");
else
    printf("NO!");
// 结果：YES! (a被赋值为7, 非0为真)

// 程序 B：相等判断
int a = 10;
if(a == 7)
    printf("YES!");
else
    printf("NO!");
// 结果：NO! (10 == 7 不成立)
易错点 ②：避免对实数作相等判断
现象 浮点数在计算机中往往不能精确表示（有舍入误差），因此直接使用 == 比较两个浮点数，结果往往不符合预期。 
// 错误做法：直接比较
int a;
a = 1.78/3.55*3.55 == 1.78;
printf("%d\n", a); // 结果可能是 0

// 正确做法：判断差值是否足够小
a = fabs(1.78/3.55*3.55 - 1.78) < 1e-6;
printf("%d\n", a); // 结果为 1
printf("%.10f", 1.21f + 1.21f); → 2.4200000763

二进制无法精确表示大多数十进制小数，运算后会有微小误差。

正确写法 fabs(x - y) < 1e-6
即“两者之差足够小”，就认为相等。
易错点 ③：正确表示数学连续不等式

❌错误写法

3 > 2 > 1

按左结合计算：
3 > 2 → 1
1 > 1 → 0
结果看似“真”，实际是 0（假）。

✅正确写法

3 > 2 && 2 > 1

用逻辑与把两个条件连起来：
1 && 1 → 1（真）

推广 数学上的 a ≤ x ≤ b，在 C 语言中必须写成：
a <= x && x <= b
小结 关系运算符的三大易错点：= 与 ==、浮点相等、连续不等式。
3.2.2　逻辑运算符
运算符含义目数优先级
!逻辑非单目2（很高）
&&逻辑与双目11
||逻辑或双目12（较低）
三条核心规则
  • 操作数可以是任意表达式，按“非 0 为真，0 为假”解释
  • 运算结果是一个逻辑量，用整数 1 表示真、0 表示假
  • 优先级：! > && > ||，低于关系运算符
3 && 5 → 1 0 || sum → 若 sum 非 0 则为 1 !5 → 0
注意 逻辑运算的整体结果永远是 0 或 1。像 (x = 3) 这类赋值表达式，其“值”确实是 3，但作为条件时按“非 0 为真”解释——不要把它和逻辑结果混为一谈。
逻辑运算真值表
ab!a!ba || ba && b
真 / 1真 / 10011
真 / 1假 / 00110
假 / 0真 / 11010
假 / 0假 / 01100
&&全真才真：只要有一个为假，结果就是 0。
||有真就真：只要有一个为真，结果就是 1。
逻辑习题①：赋值与逻辑
题目 已知 int a=3, b=10;，求下列表达式的值： 
(a=5) && (b>a) 的值为：______
(a==5) && (b>a) 的值为：______
👉 点击显示解析
解析 ① (a=5) 是赋值表达式，赋值为 5（非 0 为真）；由于 a 变成了 5，b>a 即 10>5 也为真。所以整体值为 1。
② 特别注意：由于上一行执行后 a 的值已经变成了 5，因此本行 a==5 为真，b>a 为真，整体值也为 1。（如果单独执行，a 为 3 时，该值为 0）
短路特性（short-circuit evaluation）
定义逻辑与、逻辑或的右侧表达式不一定被执行，取决于左侧结果。

🔗逻辑与 &&

a && b && c

  • 只有 a 为真时才判断 b
  • 只有 a && b 为真时才判断 c
  • 若 a 为假，表达式值已确定为假，不再往下判断

🔀逻辑或 ||

a || b || c

  • 只要 a 为真，就不必再判断
  • 结果一定为真
  • 后面的表达式不会执行
正向用途 短路也是效率与安全的护栏：把“简单、安全的判断”放左边，“稍复杂、危险的计算”放右边，左边不成立就直接跳过右边。
例如先判断能否作除数，再计算商：
if (b != 0 && a / b > 2)
若 b 为 0，左侧已为假，右侧的除法不会执行，既避免“除以 0”，也省去了多余计算。
逻辑运算典型习题
② 若有 int a=3, b=2, c=1, d=0, m=1, n=2;
表达式 (m=a>b>c) && (n=c>d) 运算后，m 的值是 ______，n 的值是 ______。
👉 点击显示解析
解析 计算左侧 m = a>b>c：先算 a>b 即 3>2 得 1；再算 1>c 即 1>1 结果为假 0。所以 m 被赋值为 0。
因为左侧整体为假，触发短路特性，右侧 (n=c>d) 不执行，n 保持原来的值 2。
影响 短路会改变“哪些表达式被求值”，如果右侧表达式含有赋值、自增、函数调用，变量值就会受影响——这是常考陷阱。
习题：短路特性与变量赋值
题目 若有如下代码，执行后 a, b, c 的值分别是多少？ 
int a=10, b=11, c=12;
int x=1, y=2, z;
c = (a = y>x) || (b = c>z);
👉 点击显示解析
解析 ① 先算左侧 (a = y>x)：y>x 即 2 > 1 为真（1），赋值给 a，所以 a = 1。左侧整体为真。
② 发生逻辑或（||）的短路：由于左侧已经为真，右侧 (b = c>z) 不会执行。
③ 因此，b 保持原来的值 11，整个表达式的值为 1，赋值给 c，所以 c = 1。
逻辑进阶：德摩根定律（De Morgan）
问题 如何对“多个条件组成的复合条件”整体取反？直接在每个条件前加 ! 是错误的。

❌错误写法

!(a && b) → !a && !b

对“与”取反，结果不是各项分别取反再“与”。

✅正确等价

!(a && b) ≡ !a || !b

!(a || b) ≡ !a && !b

“与”变“或”，“或”变“与”，各项分别取反。

记忆口诀 非（A 且 B）= 非 A 或 非 B；非（A 或 B）= 非 A 且 非 B。
例：!(year%4==0 && year%100!=0) 等价于 year%4!=0 || year%100==0。
应用 改写“否定型”条件时最有用：把 if(!(a>0 && b>0)) 写成更直观的 if(a<=0 || b<=0)。
常见逻辑条件的表示
目标用关系运算符和逻辑运算符，把数学上的判断条件翻译成 C 语言表达式。
判断目标C 语言写法
字符 ch 是大写字母ch >= 'A' && ch <= 'Z'
字符 ch 是英文字母(ch>='A'&&ch<='Z') || (ch>='a'&&ch<='z')
年份 year 是闰年year%4==0 && year%100!=0 || year%400==0
闰年规则详解 ① 能被 4 整除，且不能被 100 整除；
② 或者能被 400 整除。
两者满足其一即为闰年，因此在表达式中间使用了逻辑或 || 连接。
3.2.3　条件运算符（三目运算符）
语法格式
表达式 1 ? 表达式 2 : 表达式 3
示例
max = (a>b) ? a : b;
执行规则 表达式 1 为真（非 0）→ 取表达式 2 的值
表达式 1 为假（0）　→ 取表达式 3 的值
等价于 if…else
if(a > b)
    max = a;
else
    max = b;
特点 条件运算符是 C 语言中唯一的三目运算符，结合方向为“自右向左”，适合把简单的 if…else 写成一行。
嵌套（右结合） 多个条件运算符可嵌套使用，结合方向为自右向左：
max = a>b ? a : (b>c ? b : c);
含义：若 a>b 取 a，否则再比较 b、c 取较大者。注意加括号更清晰。
例：大小写字母转换
题目判断键盘输入的一个字符是否为大写字母，如果是则转换为小写字母，否则不转换，输出处理后的字符。
#include <stdio.h>
int main() {
    char ch;
    scanf("%c", &ch);
    ch = (ch>='A' && ch<='Z') ? (ch+32) : ch;
    printf("%c\n", ch);
    return 0;
}
说明
  • 大写字母 ASCII 码比小写字母小 32，所以 ch+32
  • 条件表达式建议加括号，可读性更好
  • 该写法等价于一个 if…else
输入：G 输出：g 输入：m 输出：m
3.2.4　位运算符（Bitwise Operators）
概念 C 语言提供了直接对整数在内存中的二进制位进行操作的运算符。位运算效率极高，常用于底层开发、嵌入式、算法优化。
学习建议 位运算偏底层。本节中带 ※ 拓展 标记的内容为拓展了解：考试一般只要求掌握「规则 + 示例」，带 ※ 的深挖部分先看懂即可，不必强记。
※ 拓展说明 为便于演示，下面的二进制示例统一用 8 位表示（实际 int 通常为 32 位，结论同样成立）。
此外，有符号数的右移在标准 C 中属于“实现定义”行为，绝大多数编译器采用算术右移（补符号位）。
位运算符一览
位运算符分类及说明
运算符名称运算规则
&按位与两位同时为 1 时，结果为 1；否则为 0
|按位或两位只要有一个为 1，结果为 1；否则为 0
^按位异或两位相同为 0，相异为 1
~按位取反单目运算符，将 1 变 0，0 变 1
<<左移高位丢弃，低位补 0。相当于乘以 2 的幂（不溢出时）
>>右移低位丢弃，高位补 0（无符号）或补符号位（有符号，通常为算术右移）。相当于除以 2 的幂（不溢出时）
记忆口诀 & 清 0、| 置 1、^ 翻转、~ 全部取反；<< 与 >> 是“整体搬家”式的移位。
位运算：按位与（&）
运算规则 两个对应的二进制位都是 1 时，结果位才为 1；否则为 0。
运算示例：5 & 3
  0000 0101  (5)
& 0000 0011  (3)
---------------
  0000 0001  (1)

// 结论：5 & 3 = 1

🧹典型应用：用掩码保留指定位

与 0 进行与运算，该位被清零；与 1 进行与运算，该位保留原值。把要保留的位对应置 1、其余置 0，就得到“掩码”。

// 取 x 的低 4 位（其余位清零）
// 掩码 = 0000 1111 (15)
y = x & 15;

// 假设 x = 0011 0110 (54)
// 0000 1111 & 0011 0110 = 0000 0110 (6)
位运算：按位或（|）
运算规则 两个对应的二进制位只要有一个为 1，结果位就为 1；全为 0 时才为 0。
运算示例：5 | 3
  0000 0101  (5)
| 0000 0011  (3)
---------------
  0000 0111  (7)

// 结论：5 | 3 = 7

🛠️典型应用：用掩码将指定位置 1

与 1 进行或运算，该位被置 1；与 0 进行或运算，该位保留原值。把要置 1 的位对应写 1，即得到“掩码”。

// 将 x 的低 4 位置 1（其余位不变）
// 掩码 = 0000 1111 (15)
x = x | 15;

// 假设 x = 0011 0000 (48)
// 0011 0000 | 0000 1111 = 0011 1111 (63)
位运算：按位异或（^）
运算规则 两个对应的二进制位相同为 0，相异为 1。
运算示例：5 ^ 3
  0000 0101  (5)
^ 0000 0011  (3)
---------------
  0000 0110  (6)

// 结论：5 ^ 3 = 6

🔄典型应用：交换两个数

利用异或的性质：a ^ a = 0，a ^ 0 = a。无需引入第三个变量即可完成交换。

int a = 5, b = 3;
a = a ^ b; // a = 6
b = a ^ b; // b = 5
a = a ^ b; // a = 3
// 结果：a=3, b=5
※ 拓展提醒仅作原理演示：实际开发请用临时变量交换。当 a、b 指向同一块内存（如数组同一元素）时异或交换会出错，且现代 CPU 上并不更快。
位运算：按位取反（~）
运算规则 单目运算符，将操作数对应的二进制位取反：1 变 0，0 变 1。
运算示例：~5
  0000 0101  (5 的位模式)
~ ---------
  1111 1010  (即 -6)

// 结论：~5 = -6
// 规律：~x = -x - 1

⚠️重要说明

~ 是按位运算：把操作数在内存中的每一个二进制位都翻转（1 变 0，0 变 1），与正负号无关。

以 5 为例，它在内存里的位模式是 0000 0101（正数时它恰好与原码、补码都相同）；~ 不管这些，直接把每一位翻转，得到 1111 1010。这个位模式在补码规则下表示 -6。

因此有恒等关系 ~x = -x - 1（即 ~5 = -5 - 1 = -6）。结果之所以为负，是补码解释的必然结果，并不是“对补码又取了一次反”。

※ 拓展注意 按位取反 ~ 和逻辑非 ! 完全不同。
!5 = 0（逻辑假），
~5 = -6（按位翻转每一位）。
位运算：左移（<<）与 右移（>>）

👈左移：<<

将二进制位向左移动，高位丢弃，低位补 0。
相当于乘以 2 的幂（x << n 相当于 x * 2^n）。

5 << 1   // 0000 0101 -> 0000 1010 (10)
5 << 2   // 0000 0101 -> 0001 0100 (20)

👉右移：>>

将二进制位向右移动，低位丢弃。
无符号数高位补 0；有符号数高位补符号位（通常为算术右移，标准 C 中属“实现定义”）。
相当于除以 2 的幂（x >> n 相当于 x / 2^n）。

5 >> 1   // 0000 0101 -> 0000 0010 (2)
20 >> 2  // 0001 0100 -> 0000 0101 (5)
※ 拓展：应用场景 移位运算比普通乘除法指令执行更快，常用于底层驱动（如寄存器配置）或算法优化。但要注意：左移不会自动防止溢出，超出的高位会被直接丢弃；此外移位位数 n 必须非负且小于数据类型的位数，否则行为未定义（UB）。
位运算综合应用

🔹① 判断奇偶

if (n & 1)        /* 最低位为 1 → 奇数 */
  puts("奇数");
else
  puts("偶数");

利用最低位：奇数最低位必为 1，n & 1 非 0 即为真。

🧮② 取反加一得相反数

y = ~x + 1;
// 补码表示下：y 就是 -x
// 例：~5 + 1 = -5

这正是计算机用补码表示负数时的规律：按位取反再加 1，等于取相反数。

🔍③ 判断两数是否相等

if ((a ^ b) == 0)
  puts("相等");
// 异或结果为 0，说明 a 与 b 每一位都相同

利用 a ^ a = 0 的性质：两数相等时异或恰为 0（注意加括号，== 优先级高于 ^）。

※④ 判断“2 的幂”

if (n > 0 && (n & (n-1)) == 0)
  puts("是 2 的幂");

2 的幂的二进制只有一个 1，n & (n-1) 会消去它。

小结 位运算的威力在于“把位当作开关”：与 1 取 & 可测试 / 清零某位，与 1 取 | 可置位，与 1 取 ^ 可翻转。下一讲用 if 组合这些位条件，就能写出精确的分支逻辑。
运算符优先级总览（由高到低）
  1. 括号　( )　[ ]
  2. 单目　++ -- ! ~ - sizeof
  3. 算术 1　* / %
  4. 算术 2　+ -
  5. 移位　<< >>
  6. 关系 1　< <= > >=
  7. 关系 2　== !=
  1. 按位与　&
  2. 按位异或　^
  3. 按位或　|
  4. 逻辑与　&&
  5. 逻辑或　||

记忆要点 ① 单目 > 双目，算术 > 移位 > 关系 > 位运算 > 逻辑 > 条件 > 赋值；
② && 高于 ||；< <= > >= 高于 == !=；
③ 不确定时，加括号永远是最稳妥的做法。
本讲小结（控制运算符）

①关系运算符

结果为 1 或 0。注意 == 与 = 的区别，避免浮点数直接比较，禁止连写不等式。

②逻辑运算符

!、&&、||。非 0 为真，注意短路特性对变量的影响。

③条件运算符

表达式1 ? 表达式2 : 表达式3。唯一的三目运算符，简化分支。

④位运算符

& | ^ ~ << >>。直接操作二进制，高效。常用于奇偶判断、掩码、快速乘除。
