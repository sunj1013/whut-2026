第 3 章　位运算基础（初学版）
主讲：孙　骏
为什么需要位运算？
核心概念 计算机底层只认识 0 和 1。位运算（Bitwise Operation）就是直接对整数在内存中的二进制位（bit）进行操作。

🎯典型应用场景

① 标志位：用一个整数存多个开关状态（如权限管理）；
② 底层开发：操作硬件寄存器、网络协议；
③ 算法优化：用移位代替乘除法，速度极快；
④ 加密与压缩：哈希算法、数据压缩的基础。

🔘生活化比喻

普通的算术是“看整体数值”；
位运算则是“精确拨动面板上的每一个开关”。它可以不改变其他位，只单独控制某一位。

移位的两个坑：符号位与边界
① 左移挤到符号位
8 位示意：0100 0000 << 1 = 1000 0000
对有符号 int，最高位变成 1 就是负数；对 unsigned 仍是正数。所以左移前先想想：乘完会不会超出范围？
② 移出边界的位就没了
8 位示意：1000 0000 << 1 = 0000 0000
移出去的位直接丢弃，不会“循环”回来，右边补 0。移位数 n 必须小于类型宽度（int 32 位，n < 32），否则结果未定义。
③ 负数右移：左边补 1
8 位示意：1111 0110 >> 2 = 1111 1101，即 −10 ÷ 4 = −2.5，算术右移向下取整得 −3。
1111 0110 是 −10 的补码；最高位是 1，右移时左边一直补 1，符号保持不变。
记法 左移只看“右边补 0”，右移只看“左边补什么”；移出的位永远丢弃，不循环。
复合赋值：让代码更简洁
与算术运算同理 x = x & 3 可以简写为 x &= 3。
同理还有：|=、^=、<<=、>>=。 
int x = 0xA5; // 二进制 1010 0101

x &= 0xF0; // 等价于 x = x & 0xF0
x |= 0x0F; // 等价于 x = x | 0x0F
x <<= 2;  // 等价于 x = x << 2
建议 在位运算中，复合赋值极其常见，因为它清楚地表达了“我要修改 x 自己的某几位”，不会引入新的临时变量。

十六进制每 1 位正好对应 4 个二进制位，所以位运算里常写成十六进制。
典型应用：精准控制“开关”（掩码）
核心思想 用 1 << k 生成一个只有第 k 位是 1 的数（掩码）。用它和原数运算，就能单独操作第 k 位。

💡四个基本操作

  • 置 1：x |= (1 << k)
  • 清 0：x &= ~(1 << k)
  • 翻转：x ^= (1 << k)
  • 测试：if (x & (1 << k))

🔐生活案例：权限管理

假设一个文件有读、写、执行权限：
READ = 1 (001), WRITE = 2 (010), EXEC = 4 (100)

int p = 0;
p |= 1; // 增加读权限
p |= 2; // 增加写权限 (现在 p=3)
if (p & 1) { /* 有读权限 */ }
p &= ~1; // 撤销读权限
典型应用：一个字节存 8 个状态
思路 一个 char 有 8 位，就是 8 个互不干扰的开关：每位代表一个状态，用置 1 / 清 0 / 测试单独操作。这里规定：位 0 = 灯，位 1 = 门，位 2 = 窗。 
char flags = 0;        // 0000 0000
flags |=  (1 << 0);    // 开灯 0000 0001
flags |=  (1 << 1);    // 开门 0000 0011
if (flags & (1 << 1))    // 测试门
    printf("门开着\n");
flags &= ~(1 << 0);    // 关灯 0000 0010

置 1 |= (1<<k)　清 0 &= ~(1<<k)　测试 & (1<<k)

价值 一个字节就能存 8 个布尔状态，省内存、判断快；每个状态只占 1 位，改一个位不影响其他位。这是嵌入式、系统程序里压缩状态标志的常见手法。
现实案例①：游戏角色的 Buff / Debuff
场景 角色身上同时挂着中毒、眩晕、无敌、加速……不必每种状态开一个变量：一个字节的 4 个位就够了——位 0 中毒、位 1 眩晕、位 2 无敌、位 3 加速。 
char state = 0;                       // 0000 0000 一切正常
state |= (1 << 0);                   // 吃了毒药 → 中毒    0000 0001
state |= (1 << 1);                   // 又踩陷阱 → 眩晕    0000 0011
state &= ~((1 << 0) | (1 << 1));       // 净化技能 → 位0、位1 清 0
if (!(state & (1 << 1)))             // 判断：还没晕？
    printf("可以行动\n");

现实案例②：微信 / QQ 的通知设置
场景 声音、震动、显示消息内容、置顶——四个开关，一个 int 全装下：位 0 声音、位 1 震动、位 2 显示内容、位 3 置顶。

位 0　声音

1 响铃，0 静音

位 1　震动

1 震动，0 不震

位 2　内容

1 显示详情，0 只提示

位 3　置顶

1 会话置顶，0 不置顶

int notify = 0;                        // 0000 0000 全部关闭
notify |= (1 << 1);                   // 静音但震动      0000 0010 (2)
notify |= (1 << 0) | (1 << 2);        // 再开声音和内容  0000 0111 (7)
notify &= ~(1 << 2);                 // 不显示内容      0000 0011 (3)
if (notify & (1 << 0)) printf("响铃\n");   // 位0 是 1 才响
省在哪 4 个开关只占 4 个位（不到 1 字节）；存库、传参、比较都只用一个整数——一次赋值就改完整套通知策略。
现实案例③：颜色值 0xAARRGGBB
场景 屏幕上每个像素的颜色都是一个 32 位整数：高 8 位是透明度 A，接着 R 红、G 绿、B 蓝各占 8 位。写成十六进制正好 8 位。 
int c = 0xFF3366CC;                  // A=FF  R=33  G=66  B=CC
int a = (c >> 24) & 0xFF;            // 0xFF = 255
int r = (c >> 16) & 0xFF;            // 0x33 = 51
int g = (c >>  8) & 0xFF;            // 0x66 = 102
int b =  c        & 0xFF;            // 0xCC = 204
int d = (a << 24) | (r << 16) | (g << 8) | b;   // 原样拼回去

右移把目标段搬到最低 8 位，再 & 0xFF 把其余段抹掉——一步“搬 + 擦”。

想一想 网页里写的 #FF0000 就是 0x00FF0000：红色在 位 23–16，所以得左移 16 位才放得进去——前端每天都在用位运算。
典型应用：异或交换两个数
技巧 利用 a ^ a = 0 和 a ^ 0 = a，不需要第三个变量也能交换 a 和 b。 
int a = 3, b = 5;

a = a ^ b; // a = 3^5 = 6
b = a ^ b; // b = 6^5 = 3
a = a ^ b; // a = 6^3 = 5
// 结果：a = 5, b = 3
了解即可，实际慎用 - 可读性差；
- 如果 a 和 b 是同一个变量（地址相同），会被清零；
- 现代编译器下，用临时变量的交换反而更快更安全。
面试或算法题常考，实际工程中少用。
典型应用：两个短小的实用案例

🔤案例 1：大小写字母互转

大写和小写，ASCII 码只差第 5 位（32）：
'a' 0110 0001 ／ 'A' 0100 0001
所以翻转第 5 位就能来回切换，不用 if。

char c = 'a';   // 0110 0001
c ^= (1 << 5);  // 翻转第 5 位

🔢案例 2：判断“是不是 2 的幂”

2 的幂（2、4、8、16…）二进制里只有一个 1；
x - 1 把这个 1 变 0、后面全变 1。
所以 x & (x - 1) 为 0 就是 2 的幂。

int x = 8;              // 1000
if (x > 0 && (x & (x-1)) == 0)
    printf("是 2 的幂");
拓展思考 二进制位就像一排排开关，位运算本质上是“批量控制开关”。这两个案例的共同点：用一次位运算，替掉一层判断或循环。
初学常见错误
❌ 混淆逻辑与位运算 & 是按位与，&& 是逻辑与。
6 & 3 结果为 2；6 && 3 结果为 1（真）。
❌ 搞混 ~ 和 ! ~5 是按位取反，结果是 -6；
!5 是逻辑非，结果是 0。
❌ 移位越界 对 32 位整数，x << 40 是未定义行为。移位不能超过类型宽度。
❌ 对浮点数用位运算 float、double 不能参与位运算，编译直接报错。
课堂练习 · 先自己算，再点开答案
1. 6 & 3、6 | 3、6 ^ 3 各是多少？
6 = 0110，3 = 0011，逐位对照 → 依次是 2、7、5
2. 把整数 x 的第 3 位（从 0 开始数）置 1，写出语句。
置 1 用“或上单点掩码”，第 k 位掩码是 1 << 3 → x |= (1 << 3);
3. 5 << 2 等于多少？它在算术上等价于什么运算？
5 << 2 = 20，等价于 5 × 2² = 5 × 4；反过来 20 >> 2 又回到 5
4. char c = 0x41;（即 'A'），再执行 c |= 0x20;，c 变成什么字母？为什么？
0x41 = 0100 0001，0x20 正好是第 5 位，或上它变 'a'（0110 0001）——这就是“转小写”
本讲小结

①按位与 &

全真才真。用于清零或保留特定位（掩码）。

②按位或 |

有真就真。用于将特定位强制置 1。

③按位异或 ^

相同为 0，不同为 1。用于翻转位或交换变量。

④按位取反 ~

单目运算，将 0 变 1，1 变 0。

⑤左移 / 右移

<< 右补 0；>> 左补符号位。等效于乘除 2 的幂。

⑥状态标志

用一个整数的不同二进制位表示多个开关。
